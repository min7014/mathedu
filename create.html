어려운 고난도 문제를 올리면, 초등·중학생도 풀 수 있는 5~8단계 인터랙티브 빌드업 퀴즈로 자동 제작되어 게시판에 배포됩니다.

⚡ 1초 예시 채우기:
비워두시면 문제 내용이나 이미지를 분석하여 자동으로 제목이 붙습니다.
텍스트를 직접 적거나, 문제 캡처 이미지를 Ctrl+V로 바로 붙여넣으세요.
이미지는 Ctrl+V · 📋 버튼 · 여기로 파일 드래그 중 편한 걸로 넣으세요
✅ 이미지가 첨부되었습니다.
