🔰 제0단계 · 수학 기호

$g'(x) = f'(x) - k$ — 함수 $g(x) = f(x) - kx$의 도함수
$g'(-1) = 0, g'(3) = 0$ — $x = -1, 3$에서 극값을 갖기 위한 필요충분조건
$f'(x) = 3x^2 + 2ax + b$ — 최고차항 계수가 1인 삼차함수의 도함수
$f(x) = x^3 - 3x^2$ — 조건을 모두 만족하는 유일한 삼차함수 식

🎯 최종 문제 + 상세 풀이

[전체 풀이 과정 종합]
1단계: 최고차항 계수가 $1$인 삼차함수 $f(x)$를 $f(x) = x^3 + ax^2 + bx + c$라 두자.
$f(0) = 0$이므로 $c = 0$이다.
도함수는 $f'(x) = 3x^2 + 2ax + b$이며, $f'(0) = 0$이므로 $b = 0$이다.
따라서 $f(x) = x^3 + ax^2$, $f'(x) = 3x^2 + 2ax$이다.
2단계: 함수 $g(x) = f(x) - kx$의 도함수는
$$g'(x) = f'(x) - k = 3x^2 + 2ax - k$$
$g(x)$가 $x = -1$과 $x = 3$에서 극값을 가지므로, 이차방정식 $g'(x) = 0$의 두 실근이 $-1$과 $3$이다.
근과 계수의 관계에 의해:
두 근의 합: $(-1) + 3 = 2 = -\frac{2a}{3} \implies 2a = -6 \implies a = -3$
두 근의 곱: $(-1) \times 3 = -3 = -\frac{k}{3} \implies k = 9$
3단계: 따라서 삼차함수는 $f(x) = x^3 - 3x^2$로 유일하게 결정된다.
4단계: 구하는 $f(2)$의 값은
$$f(2) = 2^3 - 3 \times 2^2 = 8 - 12 = -4$$
최종 본문항
최고차항 계수가 $1$인 삼차함수 $f(x)$에 대하여 $f(0) = 0$이고, 함수 $g(x) = f(x) - kx$가 $x = -1$과 $x = 3$에서 극값을 갖는다. $f'(0) = 0$일 때, $f(2)$의 값은? (단, $k$는 상수이다.)
1$-6$
2$-4$
3$-2$
4$0$
5$2$
어떤 부분이 이상한가요? 자세히 적어주세요.
