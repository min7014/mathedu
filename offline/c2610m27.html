📋 [문제 분석 및 핵심 출제 의도]

본 문항은 구간별로 정의된 지수함수의 미분가능성과 역함수의 미분법을 결합한 문항입니다.

📐 [단계별 상세 풀이 전개]

1단계: $x = b$에서의 미분가능 조건으로 $e^b$와 $a$ 구하기
미분계수가 일치해야 하므로 $2e^{2b} = 2e^b + 8e^{-b}$입니다. $t = e^b > 0$이라 하면:
$$t^3 - t^2 - 4 = (t - 2)(t^2 + t + 2) = 0 \implies t = e^b = 2$$ 연속 조건 $e^{2b} - 2 = 2e^b - 8e^{-b} + a$에 $e^b = 2$를 대입하면 $4 - 2 = 4 - 4 + a \implies a = 2$입니다.

2단계: 역함수의 미분법으로 $g'(8)$ 구하기
$f(b) = 2 < 8$이므로 $f(c) = 8$인 $c$는 $c > b$에 존재합니다:
$$2e^c - 8e^{-c} + 2 = 8 \implies (e^c - 4)(e^c + 1) = 0 \implies e^c = 4$$ 따라서 $f'(c) = 2e^c + 8e^{-c} = 2(4) + 8\left(\frac{1}{4}\right) = 10$이므로:
$$g'(8) = \frac{1}{f'(c)} = \frac{1}{10}$$

✨ [정답 도출 및 실전 점검 포인트]

따라서 $g'(8) = \dfrac{1}{10}$이므로 정답은 ④번입니다.

📋 [Problem Analysis & Core Concepts]

This problem combines differentiability at a boundary point with the Inverse Function Theorem.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Continuity and differentiability at $x = b$
$$2e^{2b} = 2e^b + 8e^{-b} \implies e^b = 2, \quad e^{2b} - 2 = 2e^b - 8e^{-b} + a \implies a = 2$$
Step 2: Derivative of the inverse at $y = 8$
From $2e^c - 8e^{-c} + 2 = 8$, we get $e^c = 4$. Thus $f'(c) = 2(4) + 8(1/4) = 10$ and $g'(8) = \frac{1}{10}$.

✨ [Final Answer & Practical Tips]

The correct answer is choice ④ ($\dfrac{1}{10}$).
