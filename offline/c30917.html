[풀이]
$f'(x) = 6x^2 + 2x + 1$의 한 부정적분은
$$f(x) = \int (6x^2 + 2x + 1)dx = 2x^3 + x^2 + x + C$$
(단, $C$는 적분상수)
$f(0) = 1$이므로
$$f(0) = C = 1$$
따라서
$$f(x) = 2x^3 + x^2 + x + 1$$
구하는 값은
$$f(1) = 2(1)^3 + 1^2 + 1 + 1 = 2 + 1 + 1 + 1 = 5$$
정답은 5 입니다.
