제2단계 · $f(t) = -1$을 만족시키는 $t$의 값 구하기Step 2 · Find the value of $t$ that satisfies $f(t) = -1$

먼저 알아야 할 지식

$0 \le t < \pi$에서 $\sin t - 1 = -1 \implies \sin t = 0 \implies t = 0$. $\pi \le t \le 2\pi$에서 $-\sqrt{2}\sin t - 1 = -1 \implies \sin t = 0 \implies t = \pi, 2\pi$. 따라서 $t = 0, \pi, 2\pi$ 입니다.
Prerequisite Knowledge: $0 \le t < \pi$ to $\sin t - 1 = -1 \implies \sin t = 0 \implies t = 0$. $\pi \le t \le 2\pi$ to $-\sqrt{2}\sin t - 1 = -1 \implies \sin t = 0 \implies t = \pi, 2\pi$. Hence $t = 0, \pi, 2\pi$.

함수 $y=f(x)$의 그래프를 구간별로 분석합니다.
1) $0 \le x < \pi$에서 $y = \sin x - 1$: 최댓값은 $f(\pi/2) = 0$, 최솟값은 $f(0) = -1$
2) $\pi \le x \le 2\pi$에서 $y = -\sqrt{2}\sin x - 1$: 최댓값은 $f(3\pi/2) = \sqrt{2}-1$, 최솟값은 $f(\pi) = f(2\pi) = -1$
방정식 $f(x) = f(t)$의 서로 다른 실근의 개수가 3이라는 것은 직선 $y=f(t)$와 $y=f(x)$의 교점이 3개라는 뜻입니다.
그래프에서 교점이 3개인 수평선은 $y = -1$ 과 $y = 0$ 뿐입니다.
(i) $f(t) = -1$ 일 때:
$\sin t = 0$ 이어야 하므로
$$t = 0, \quad t = \pi, \quad t = 2\pi$$
(ii) $f(t) = 0$ 일 때:
$0 \le t < \pi$에서 $\sin t - 1 = 0 \implies t = \frac{\pi}{2}$
$\pi \le t \le 2\pi$에서 $-\sqrt{2}\sin t - 1 = 0 \implies \sin t = -\frac{\sqrt{2}}{2} \implies t = \frac{5\pi}{4} \text{ 또는 } t = \frac{7\pi}{4}$
(i)과 (ii)의 모든 $t$의 값의 합은
$$0 + \pi + 2\pi + \frac{\pi}{2} + \frac{5\pi}{4} + \frac{7\pi}{4} = 3\pi + \frac{\pi}{2} + 3\pi = \frac{13\pi}{2}$$
따라서 $p = 2, q = 13$이며, 둘은 서로소입니다.
$$p + q = 2 + 13 = 15$$
정답은 15 입니다.
