📐 [단계별 상세 풀이 전개]

1단계: 삼각함수 사이의 관계식 적용
$\sin^2\theta + \cos^2\theta = 1$의 양변을 $\cos^2\theta$로 나누면 $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$이 성립합니다. $\tan^2\theta = 2$를 대입하면:
$$\frac{1}{\cos^2\theta} = 1 + 2 = 3 \implies \cos^2\theta = \frac{1}{3}$$
2단계: 사분면의 부호 결정
주어진 각의 범위 $\dfrac{\pi}{2} < \theta < \pi$는 제2사분면이므로 $\cos\theta < 0$입니다. 따라서:
$$\cos\theta = -\frac{1}{\sqrt{3}} = -\frac{\sqrt{3}}{3}$$

      • 단계 확인 정답 ($3$): $1 + 2 = 3$이므로 빗변의 제곱은 $3$, 빗변의 길이는 $\sqrt{3}$이 됩니다.
  • 🌿 2단계 · [삼각함수 관계식] $\cos^2\theta$의 값 구하기
      • 핵심 개념 및 원리: 삼각함수 공식 $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$에 $\tan^2\theta = 2$를 넣으면 $1 + 2 = 3 = \dfrac{1}{\cos^2\theta}$이 됩니다. 양변을 뒤집으면 $\cos^2\theta = \dfrac{1}{3}$입니다.

  • 💎 4단계 · [분모의 유리화] $-\dfrac{1}{\sqrt{3}}$을 유리화하여 정답 구하기
      • 핵심 개념 및 원리: $\cos^2\theta = \dfrac{1}{3}$이고 $\cos\theta < 0$이므로 $\cos\theta = -\dfrac{1}{\sqrt{3}}$입니다. 분모와 분자에 똑같이 $\sqrt{3}$을 곱하면 $-\dfrac{\sqrt{3}}{3}$이 됩니다.
      • 단계 확인 정답 ($-\dfrac{\sqrt{3}}{3}$): 분모와 분자에 $\sqrt{3}$을 곱하면 $-\dfrac{1 \times \sqrt{3}}{\sqrt{3} \times \sqrt{3}} = -\dfrac{\sqrt{3}}{3}$입니다.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Apply $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$
$$\frac{1}{\cos^2\theta} = 1 + 2 = 3 \implies \cos^2\theta = \frac{1}{3}$$
Step 2: Apply the Quadrant II sign condition
Since $\dfrac{\pi}{2} < \theta < \pi$, $\cos\theta < 0$, which yields:
$$\cos\theta = -\frac{1}{\sqrt{3}} = -\frac{\sqrt{3}}{3}$$

      • Core Principle: In a right triangle with base $1$ and height $\sqrt{2}$, the square of the hypotenuse is $1^2 + (\sqrt{2})^2 = 1 + 2 = 3$.
      • Step Verification ($3$): $1 + 2 = 3$, so the hypotenuse squared is $3$.
  • 🌿 Step 2 · [Trigonometric Identity] Finding $\cos^2\theta$
      • Core Principle: Substituting $\tan^2\theta = 2$ into $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$ gives $\dfrac{1}{\cos^2\theta} = 3 \implies \cos^2\theta = \dfrac{1}{3}$.
      • Step Verification ($\frac{1}{3}$): Since $\dfrac{1}{\cos^2\theta} = 3$, taking the reciprocal gives $\cos^2\theta = \dfrac{1}{3}$.
  • 🌱 Step 3 · [Quadrant Sign] Sign of $\cos\theta$ in Quadrant II
      • Core Principle: For $\dfrac{\pi}{2} < \theta < \pi$ (Quadrant II, upper-left), $\cos\theta$ corresponds to the $x$-coordinate, which is negative ($-$).
      • Step Verification ($\cos\theta < 0$ (음수)): In Quadrant II, only sine is positive; cosine is negative ($\cos\theta < 0$).
  • 💎 Step 4 · [Rationalizing Denominator] Rewriting $-\dfrac{1}{\sqrt{3}}$
      • Core Principle: Since $\cos^2\theta = \dfrac{1}{3}$ and $\cos\theta < 0$, $\cos\theta = -\dfrac{1}{\sqrt{3}} = -\dfrac{\sqrt{3}}{3}$.
      • Step Verification ($-\dfrac{\sqrt{3}}{3}$): Multiplying numerator and denominator by $\sqrt{3}$ yields $-\dfrac{\sqrt{3}}{3}$.

The value of $\cos\theta$ is $-\dfrac{\sqrt{3}}{3}$, corresponding to Option ①.
