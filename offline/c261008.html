📐 [단계별 상세 풀이 전개]

1단계: 첫 번째 조건에서 $a$와 $b$의 관계 도출
로그의 정의에 의하여 $\log_a b = 2 \iff b = a^2$입니다. 이때 구하는 식은 $\dfrac{b}{a} = \dfrac{a^2}{a} = a$가 됩니다.

2단계: 두 번째 조건에 대입하여 밑 통일하기
$4 = 2^2$이고 $b = a^2$이므로:
$$\log_4 b = \log_{2^2} (a^2) = \frac{2}{2}\log_2 a = \log_2 a$$
따라서 두 번째 식은 다음과 같이 정리됩니다:
$$\log_2 a + \log_4 b = 2\log_2 a = 8 \implies \log_2 a = 4 \implies a = 2^4 = 16$$

🪜 [초등 눈높이 디딤돌 전 단계(1단계~4단계) 완전 연결 상세 해설]

위 디딤돌 문제에서 밟아 온 $1$단계부터 $4$단계까지의 작은 조각들을 순서대로 연결하면 본문항의 풀이가 빈틈없이 완성됩니다.

  • 🔰 1단계 · [초등 거듭제곱 연계] $2$를 $4$번 곱하면 얼마일까?
      • 핵심 개념 및 원리: 초등학교 곱셈으로 $2 \times 2 \times 2 \times 2$를 계산해 봅시다. $2 \times 2 = 4$, $4 \times 2 = 8$, $8 \times 2 = 16$입니다.
      • 단계 확인 정답 ($16$): $2 \times 2 = 4$이고 $4 \times 4 = 16$이므로 $2^4 = 16$입니다.
  • 🌿 2단계 · [기호 번역] $\log_a b = 2$를 거듭제곱으로 바꾸기
      • 핵심 개념 및 원리: 로그 기호 $\log_a b = 2$는 '$a$를 $2$제곱하면 $b$가 된다'는 뜻입니다. 따라서 $b = a^2$이고, 양변을 $a$로 나누면 문제에서 묻는 $\dfrac{b}{a} = \dfrac{a^2}{a} = a$가 됩니다!
      • 단계 확인 정답 ($a$): $\dfrac{b}{a} = \dfrac{a^2}{a} = a$이므로, 결국 $a$의 값만 구하면 바로 정답이 됩니다!
  • 🌱 3단계 · [로그의 성질] $\log_4 b = \log_{2^2}(a^2)$ 간단히 하기
      • 핵심 개념 및 원리: $4 = 2^2$이고 $b = a^2$이므로 $\log_4 b = \log_{2^2}(a^2)$입니다. 밑의 지수 $2$와 진수의 지수 $2$가 똑같이 앞으로 나가 약분($\frac{2}{2} = 1$)되므로 $\log_2 a$와 같아집니다.
      • 단계 확인 정답 ($2\log_2 a$): $\log_4 b = \log_2 a$이므로 $\log_2 a + \log_4 b = \log_2 a + \log_2 a = 2\log_2 a$입니다.
  • 💎 4단계 · [방정식 풀이] $2\log_2 a = 8$에서 $a$ 구하기
      • 핵심 개념 및 원리: $2\log_2 a = 8$의 양변을 $2$로 나누면 $\log_2 a = 4$입니다. 즉 '$2$를 $4$제곱하면 $a$가 된다'는 뜻이므로 $a = 2^4 = 16$입니다.
      • 단계 확인 정답 ($16$): 1단계에서 계산한 것처럼 $2^4 = 16$이므로 $\dfrac{b}{a} = 16$입니다.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Express $b$ in terms of $a$
$$\log_a b = 2 \implies b = a^2 \implies \frac{b}{a} = a$$
Step 2: Simplify the second equation
$$\log_4 b = \log_{2^2}(a^2) = \log_2 a \implies 2\log_2 a = 8 \implies \log_2 a = 4 \implies a = 2^4 = 16$$

Connecting each elementary-grounded scaffolding step from Step 1 to Step 4 completes the entire derivation without any logical gaps:

  • 🔰 Step 1 · [Elementary Multiplication Link] Multiplying $2$ four times ($2^4$)
      • Core Principle: In elementary multiplication, $2 \times 2 \times 2 \times 2 = 4 \times 4 = 16$.
      • Step Verification ($16$): $2^4 = 16$.
  • 🌿 Step 2 · [Symbol Translation] Translating $\log_a b = 2$ into exponents
      • Core Principle: $\log_a b = 2$ means $b = a^2$. Therefore, the target ratio $\dfrac{b}{a} = \dfrac{a^2}{a} = a$!
      • Step Verification ($a$): $\dfrac{b}{a} = \dfrac{a^2}{a} = a$, so finding $a$ directly gives the final answer.
  • 🌱 Step 3 · [Logarithm Property] Simplifying $\log_4(a^2)$
      • Core Principle: Since $4 = 2^2$ and $b = a^2$, $\log_4 b = \log_{2^2}(a^2) = \dfrac{2}{2}\log_2 a = \log_2 a$.
      • Step Verification ($2\log_2 a$): $\log_2 a + \log_2 a = 2\log_2 a$.
  • 💎 Step 4 · [Solving for $a$] Finding $a$ from $2\log_2 a = 8$
      • Core Principle: From $2\log_2 a = 8$, we get $\log_2 a = 4 \implies a = 2^4 = 16$.
      • Step Verification ($16$): $a = 2^4 = 16$, so $\dfrac{b}{a} = 16$.

✨ [Conclusion & Key Takeaway]

Therefore, $\dfrac{b}{a} = 16$, which corresponds to Option ④.
