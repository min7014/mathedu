직사각형의 핵심 성질: 대각선이 서로 이등분한다

직사각형 $ABCD$에서 대각선 $AC$와 $BD$는 서로의 중점을 공유해요.
즉, 선분 $AC$의 중점과 선분 $BD$의 중점이 같아요.
점 $A(x_A, y_A)$, $B(x_B, y_B)$, $C(x_C, y_C)$, $D(x_D, y_D)$라고 하면:

역함수 대칭이 직사각형을 만드는 이유

점 $A$, $B$가 $y = a^x$ 위의 교점이고, 점 $C$, $D$가 $y = \log_a(x-\dfrac{1}{4})-\dfrac{1}{4}$ 위의 교점이에요.
두 함수가 역함수 관계($y=x$에 대해 대칭)이므로, 변환 $T(x,y) = (y+\dfrac{1}{4}, x-\dfrac{1}{4})$는 대칭이동을 만들어요.
$C = T(B)$, $D = T(A)$로 놓으면, 대칭에 의해 선분 $AC$와 $BD$의 중점이 자동으로 같아지고,
$\vec{AB} \perp \vec{AD}$까지 성립하면서 직사각형이 완성돼요!
문항

🔰 제3-7단계 · 교점이 반드시 대칭관계가 될 수밖에 없는 이유

엄밀한 증명

$f(x) = a^x$, $g(x) = 2x^2 - \dfrac{7}{2}x + 3$이라고 하면, 교점 $A$는 $f(x_A) = g(x_A)$를 만족해요.
$T(A) = (g(x_A)+\dfrac{1}{4}, x_A-\dfrac{1}{4}) = (y', x')$이라고 하면:
$x' = y' + \dfrac{1}{4}$이고, $y' = \log_a(x'-\dfrac{1}{4})-\dfrac{1}{4}$를 만족해요.
즉, $T(A)$는 로그함수 $y = \log_a(x-\dfrac{1}{4})-\dfrac{1}{4}$ 위의 점!
또한 $T(A)$는 포물선2 $y = 2x^2 - \dfrac{15}{2}x + \dfrac{15}{2}$ 위의 점이에요.
따라서 $T(A)$는 로그함수 ∩ 포물선2의 교점! $T$가 전단사이므로 모든 교점 $A, B$에 대해 성립해요.

3$T$가 전단사(일대일 대응)이다

🔰 제3-8단계 · C, D가 실제로 교점이라는 보장

핵심 의문

변환 $T$로 점 $A$, $B$를 옮겨 $C = T(B)$, $D = T(A)$로 놓았어요.
그런데 이 $C$, $D$가 정말로 로그함수와 두 번째 포물선의 교점일까요?
그것을 어떻게 보장할 수 있을까요?
문항
점 $(x, y)$가 $y = a^x$ 위에 있을 때, 변환 $T(x,y) = (y+\dfrac{1}{4}, x-\dfrac{1}{4})$로 옮긴 점이 $y' = \log_a(x'-\dfrac{1}{4}) - \dfrac{1}{4}$ 위에 있음을 보이는 것은?
1$\log_a(y + \dfrac{1}{4}) = x + \dfrac{1}{4}$이므로
2$\log_a(y) - \dfrac{1}{4} = x - \dfrac{1}{4}$이므로
3$\log_a(x - \dfrac{1}{4}) = y - \dfrac{1}{4}$이므로
4$\log_a(x + \dfrac{1}{4}) = y + \dfrac{1}{4}$이므로
5보장할 수 없다
어떤 부분이 이상한가요? 자세히 적어주세요.
✅ 신고가 접수되었어요. 확인 후 고칠게요!

포물선도 같은 방법으로 확인

첫 번째 포물선 $y = 2x^2 - \dfrac{7}{2}x + 3$ 위의 점 $(x, y)$를 $T$로 옮기면:
$x' = y + \dfrac{1}{4} = 2x^2 - \dfrac{7}{2}x + \dfrac{13}{4}$
$y' = x - \dfrac{1}{4}$
이 점이 두 번째 포물선 $y' = 2x'^2 - \dfrac{15}{2}x' + \dfrac{15}{2}$ 위에 있는지 확인하면:
$x = y' + \dfrac{1}{4}$를 $x'$에 대입하여 정리하면 두 포물선이 정확히 일치함을 알 수 있어요.
주의: 두 포물선 자체가 대칭관계인 것은 아니에요. 포물선1 위의 점을 $T$로 옮기면 포물선2 위의 점이 된다는 뜻이에요.

1서로 대칭이다

🔰 제4-1단계 · 기하학적 기초: 평행이동

포물선의 평행이동

포물선 $y = 2x^2 - \dfrac{7}{2}x + 3$과 $y = 2x^2 - \dfrac{15}{2}x + \dfrac{15}{2}$는 모양이 완전히 같아요.
$x^2$의 계수가 둘 다 2이므로, 한 포물선을 평행이동하면 다른 포물선이 돼요.
