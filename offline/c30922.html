제1단계 · 점화식의 분기 구조 파악하기

먼저 알아야 할 지식

🎯 최종 문제 + 상세 풀이

[풀이]
조건 (나)에 의하여 각 항의 점화식은 다음과 같이 두 갈래로 나뉩니다.
$$a_{n+1} = a_n - \frac{2k}{3} \quad \text{또는} \quad a_{n+1} = -k a_n$$
$a_1 = k > 0$이므로
$$a_2 = k - \frac{2k}{3} = \frac{k}{3} \quad \text{또는} \quad a_2 = -k(k) = -k^2$$
조건 (가)에서 $a_2 a_3 < 0$이므로 두 항의 부호가 반대이어야 합니다.
경우를 나누어 $a_5 = 0$이 되는 양수 $k$를 추적합니다.
[경우 1] $a_2 = \frac{k}{3} > 0$일 때 ($a_3 < 0$)
- $a_3 = -\frac{k}{3}$ 일 때: $a_4$와 $a_5$를 계산하면 $k = 2$ ($k^2 = 4$) 및 $k = \sqrt{2}$ ($k^2 = 2$)를 얻습니다.
- $a_3 = -\frac{k^2}{3}$ 일 때: $a_5 = 0$에서 실근이 존재하지 않거나 중복됩니다.
[경우 2] $a_2 = -k^2 < 0$일 때 ($a_3 > 0$)
- $a_3 = -k(-k^2) = k^3 > 0$ 일 때: 계산하면 $k = \frac{2}{\sqrt{3}}$ ($k^2 = \frac{4}{3}$) 및 $k = \sqrt{\frac{2}{3}}$ ($k^2 = \frac{2}{3}$)를 얻습니다.
따라서 $a_5 = 0$을 만족시키는 서로 다른 모든 양수 $k$의 값은
$$k = 2, \quad \sqrt{2}, \quad \frac{2}{\sqrt{3}}, \quad \sqrt{\frac{2}{3}}$$
구하는 $k^2$의 값의 합은
$$2^2 + (\sqrt{2})^2 + \left(\frac{2}{\sqrt{3}}\right)^2 + \left(\sqrt{\frac{2}{3}}\right)^2 = 4 + 2 + \frac{4}{3} + \frac{2}{3} = 6 + 2 = 8$$
정답은 8 입니다.
