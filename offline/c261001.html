📋 [문제 분석 및 핵심 출제 의도]

본 문항은 거듭제곱근의 성질과 유리수 지수법칙을 활용하여 식을 간단히 계산할 수 있는지를 평가합니다. 근호($\sqrt[3]{\ }$)를 분수 지수로 바꾸고 합성수 밑($4$)을 소수 밑($2$)으로 통일하면 초등학교 분수 연산만으로 쉽게 해결할 수 있습니다.

📐 [단계별 상세 풀이 전개]

1단계: 세제곱근을 분수 지수로 변환하기
거듭제곱근과 유리수 지수의 정의 $\sqrt[n]{a} = a^{\frac{1}{n}}$에 의하여 앞의 항을 변환합니다:
$$\sqrt[3]{2} = 2^{\frac{1}{3}}$$
2단계: 밑을 $2$로 통일하고 지수 곱하기
$4 = 2^2$이므로 지수법칙 $(a^m)^n = a^{mn}$을 적용합니다:
$$4^{-\frac{2}{3}} = (2^2)^{-\frac{2}{3}} = 2^{2 \times \left(-\frac{2}{3}\right)} = 2^{-\frac{4}{3}}$$
3단계: 밑이 같은 거듭제곱의 곱셈
밑이 $2$로 같으므로 지수끼리 더합니다 ($a^p \times a^q = a^{p+q}$):
$$2^{\frac{1}{3}} \times 2^{-\frac{4}{3}} = 2^{\frac{1}{3} - \frac{4}{3}} = 2^{-\frac{3}{3}} = 2^{-1} = \frac{1}{2}$$

✨ [정답 도출 및 실전 점검 포인트]

따라서 구하는 값은 $\dfrac{1}{2}$이며, 정답은 ②번입니다.
💡 실전 팁: 지수에 음수($-1$)가 나왔을 때 값을 음수로 착각하지 말고 항상 역수($\frac{1}{a}$)로 바꾸는 습관을 기르세요.

📋 [Problem Analysis & Core Concepts]

This problem evaluates the ability to simplify expressions involving radicals and rational exponents by converting radicals into fractional powers and unifying the base to $2$.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Convert the cube root into a fractional exponent
By definition $\sqrt[n]{a} = a^{\frac{1}{n}}$, we have:
$$\sqrt[3]{2} = 2^{\frac{1}{3}}$$
Step 2: Unify the base to $2$
Since $4 = 2^2$, applying $(a^m)^n = a^{mn}$ gives:
$$4^{-\frac{2}{3}} = (2^2)^{-\frac{2}{3}} = 2^{-\frac{4}{3}}$$
Step 3: Add exponents and evaluate
$$2^{\frac{1}{3}} \times 2^{-\frac{4}{3}} = 2^{\frac{1}{3} - \frac{4}{3}} = 2^{-1} = \frac{1}{2}$$

✨ [Conclusion & Key Takeaway]

The value of the expression is $\dfrac{1}{2}$, which corresponds to Option ②.
