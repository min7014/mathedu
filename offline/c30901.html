🔰 제0단계 · 수학 기호

$\sqrt[n]{a} = a^{\dfrac{1}{n}}$ — 거듭제곱근의 유리수 지수 표현
$(a^m)^n = a^{mn}$ — 지수의 거듭제곱 법칙
$a^m \div a^n = a^{m-n}$ — 밑이 같은 지수의 나눗셈
$32 = 2^5, 4 = 2^2$ — 2의 거듭제곱으로 밑 통일

제3단계 · 지수의 나눗셈 법칙 적용하기

먼저 알아야 할 지식

[풀이]
분자와 분모를 밑이 2인 거듭제곱 지수 형태로 변형합니다.
분자: $\sqrt[4]{32} = (2^5)^{\frac{1}{4}} = 2^{\frac{5}{4}}$
분모: $\sqrt[8]{4} = (2^2)^{\frac{1}{8}} = 2^{\frac{2}{8}} = 2^{\frac{1}{4}}$
따라서 주어진 식은
$$\frac{\sqrt[4]{32}}{\sqrt[8]{4}} = \frac{2^{\frac{5}{4}}}{2^{\frac{1}{4}}} = 2^{\frac{5}{4} - \frac{1}{4}} = 2^1 = 2$$
