🔰 제0단계 · 수학 기호

y = 2x\sqrt{x\sin x^2} — 단면 반원의 지름
S(x) = \frac{\pi}{8}y^2 = \frac{\pi}{2}x^3\sin x^2 — x축에 수직인 단면(반원)의 넓이
V = \int_{\sqrt{\pi/6}}^{\sqrt{\pi/2}} S(x)dx — 정적분을 이용한 입체도형의 부피

제1단계 · 단면인 반원의 넓이 $S(x)$ 구하기

먼저 알아야 할 지식

단면이 반원이고 지름이 $y$이므로 반지름은 $\frac{y}{2}$입니다. 단면적 $S(x) = \frac{1}{2}\pi \left(\frac{y}{2}\right)^2 = \frac{\pi}{8}y^2$. $y^2 = 4x^2(x\sin x^2) = 4x^3\sin x^2$ 이므로 $S(x) = \frac{\pi}{8}(4x^3\sin x^2) = \frac{\pi}{2}x^3\sin x^2$ 입니다.
문항
지름이 $y = 2x\sqrt{x\sin x^2}$인 반원의 넓이 $S(x)$는?
1$\frac{\pi}{2}x^3\sin x^2$
2$\pi x^3\sin x^2$
3$\frac{\pi}{4}x^3\sin x^2$
4$2\pi x^3\sin x^2$
5$\frac{\pi}{8}x^3\sin x^2$
어떤 부분이 이상한가요? 자세히 적어주세요.

제2단계 · 치환적분 적용하기

먼저 알아야 할 지식

$t = x^2$으로 치환하면 $dt = 2x dx \implies x dx = \frac{1}{2}dt$. 적분 구간은 $x = \sqrt{\pi/6} \to t = \pi/6$, $x = \sqrt{\pi/2} \to t = \pi/2$ 입니다. 따라서 부피 $V = \int \frac{\pi}{2}x^2(x\sin x^2)dx = \frac{\pi}{4}\int_{\pi/6}^{\pi/2} t\sin t dt$ 가 됩니다.
문항
$t = x^2$으로 치환한 후의 적분식은?
1$\frac{\pi}{4}\int_{\pi/6}^{\pi/2} t\sin t dt$
2$\frac{\pi}{2}\int_{\pi/6}^{\pi/2} t\sin t dt$
3$\pi \int_{\pi/6}^{\pi/2} t\sin t dt$
4$\frac{\pi}{4}\int_{0}^{\pi/2} t\sin t dt$
5$\frac{\pi}{8}\int_{\pi/6}^{\pi/2} t\sin t dt$
어떤 부분이 이상한가요? 자세히 적어주세요.
✅ 신고가 접수되었어요. 확인 후 고칠게요!

제3단계 · 부분적분으로 부피 계산 완성하기

먼저 알아야 할 지식

$\int t\sin t dt = -t\cos t + \sin t$. 위끝 $\pi/2$를 대입하면 $0+1 = 1$, 아래끝 $\pi/6$을 대입하면 $-\frac{\pi}{6}\frac{\sqrt{3}}{2} + \frac{1}{2}$. 차이는 $1 - (-\frac{\sqrt{3}\pi}{12} + \frac{1}{2}) = \frac{1}{2} + \frac{\sqrt{3}\pi}{12} = \frac{\sqrt{3}\pi+6}{12}$. 따라서 $V = \frac{\pi}{4} \times \frac{\sqrt{3}\pi+6}{12} = \frac{\sqrt{3}\pi^2+6\pi}{48}$ 입니다.
문항
$\frac{\pi}{4} \times \frac{\sqrt{3}\pi+6}{12}$ 의 계산 결과는?
1$\frac{\pi^2+6\pi}{48}$
2$\frac{\sqrt{2}\pi^2+6\pi}{48}$
3$\frac{\sqrt{3}\pi^2+6\pi}{48}$
4$\frac{\sqrt{2}\pi^2+12\pi}{48}$
5$\frac{\sqrt{3}\pi^2+12\pi}{48}$
어떤 부분이 이상한가요? 자세히 적어주세요.

🎯 최종 문제 + 상세 풀이

[풀이]
$\sqrt{\frac{\pi}{6}} \le x \le \sqrt{\frac{\pi}{2}}$인 $x$에 대하여 $x$축에 수직인 평면으로 자른 단면은 지름이 $y$인 반원입니다.
단면의 넓이를 $S(x)$라 하면
$$S(x) = \frac{1}{2}\pi \left(\frac{y}{2}\right)^2 = \frac{\pi}{8}y^2$$
$$y^2 = (2x\sqrt{x\sin x^2})^2 = 4x^2(x\sin x^2) = 4x^3\sin x^2$$
$$S(x) = \frac{\pi}{8}(4x^3\sin x^2) = \frac{\pi}{2}x^3\sin x^2$$
입체도형의 부피 $V$는 다음과 같습니다.
$$V = \int_{\sqrt{\frac{\pi}{6}}}^{\sqrt{\frac{\pi}{2}}} \frac{\pi}{2}x^3\sin x^2 dx$$
$t = x^2$으로 치환하면 $dt = 2x dx \implies x dx = \frac{1}{2}dt$ 입니다.
$$V = \frac{\pi}{4}\int_{\frac{\pi}{6}}^{\frac{\pi}{2}} t\sin t dt$$
부분적분법을 적용하면
$$\int t\sin t dt = -t\cos t - \int (-\cos t)dt = -t\cos t + \sin t$$
$$\left[-t\cos t + \sin t\right]_{\frac{\pi}{6}}^{\frac{\pi}{2}} = (0 + 1) - \left(-\frac{\pi}{6} \times \frac{\sqrt{3}}{2} + \frac{1}{2}\right) = \frac{1}{2} + \frac{\sqrt{3}\pi}{12} = \frac{\sqrt{3}\pi + 6}{12}$$
따라서 부피는
$$V = \frac{\pi}{4} \times \frac{\sqrt{3}\pi + 6}{12} = \frac{\sqrt{3}\pi^2 + 6\pi}{48}$$
정답은 ③번입니다.
최종 본문항
그림과 같이 곡선 $y=2x\sqrt{x\sin x^2}$ ($0 \le x \le \sqrt{\pi}$)와 $x$축 및 두 직선 $x=\sqrt{\frac{\pi}{6}}, x=\sqrt{\frac{\pi}{2}}$로 둘러싸인 부분을 밑면으로 하는 입체도형이 있다. 이 입체도형을 $x$축에 수직인 평면으로 자른 단면이 모두 반원일 때, 이 입체도형의 부피는? [3점]
1$\frac{\pi^2+6\pi}{48}$
2$\frac{\sqrt{2}\pi^2+6\pi}{48}$
3$\frac{\sqrt{3}\pi^2+6\pi}{48}$
4$\frac{\sqrt{2}\pi^2+12\pi}{48}$
5$\frac{\sqrt{3}\pi^2+12\pi}{48}$
어떤 부분이 이상한가요? 자세히 적어주세요.
