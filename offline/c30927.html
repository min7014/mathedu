🔰 제0단계 · 수학 기호

$f(x) + f(\dfrac{1}{2}\sin x) = \sin x$ — 함수방정식 조건
$\{f(\dfrac{1}{2}\sin x)\}' = f'(\dfrac{1}{2}\sin x) \times \dfrac{1}{2}\cos x$ — 합성함수의 미분법
$f'(0) = \dfrac{2}{3}, f'(\pi) = -\dfrac{2}{3}$ — 특수각 x=0, pi 대입 결과

제1단계 · 양변을 합성함수 미분법으로 미분하기

먼저 알아야 할 지식

주어진 등식 $f(x) + f(\frac{1}{2}\sin x) = \sin x$의 양변을 $x$에 대해 미분하면 $f'(x) + f'(\frac{1}{2}\sin x) \cdot \frac{1}{2}\cos x = \cos x$ 입니다.

4$\frac{1}{2}f'(\cos x)$
5$f'(\frac{1}{2}\cos x)$

제2단계 · $x=0$을 대입하여 $f'(0)$ 구하기

먼저 알아야 할 지식

$x=0$을 대입하면 $\sin 0 = 0, \cos 0 = 1$이므로 $f'(0) + f'(0) \cdot \frac{1}{2} = 1 \implies \frac{3}{2}f'(0) = 1 \implies f'(0) = \frac{2}{3}$ 입니다.

제3단계 · $x=\pi$를 대입하여 $f'(\pi)$ 구하기

먼저 알아야 할 지식

$x=\pi$를 대입하면 $\sin \pi = 0, \cos \pi = -1$이므로 $f'(\pi) + f'(0) \cdot (-\frac{1}{2}) = -1 \implies f'(\pi) - \frac{1}{2}(\frac{2}{3}) = -1 \implies f'(\pi) - \frac{1}{3} = -1 \implies f'(\pi) = -\frac{2}{3}$ 입니다.

🎯 최종 문제 + 상세 풀이

[풀이]
주어진 등식
$$f(x) + f\left(\frac{1}{2}\sin x\right) = \sin x$$
의 양변을 $x$에 대하여 미분하면 합성함수의 미분법에 의해
$$f'(x) + f'\left(\frac{1}{2}\sin x\right) \times \frac{1}{2}\cos x = \cos x \quad \cdots\cdots \text{㉠}$$
㉠에 $x = 0$을 대입하면 ($\sin 0 = 0, \cos 0 = 1$)
$$f'(0) + f'(0) \times \frac{1}{2} = 1$$
$$\frac{3}{2}f'(0) = 1 \implies f'(0) = \frac{2}{3}$$
이제 ㉠에 $x = \pi$를 대입하면 ($\sin \pi = 0, \cos \pi = -1$)
$$f'(\pi) + f'(0) \times \left(-\frac{1}{2}\right) = -1$$
$$f'(\pi) - \frac{1}{2}\left(\frac{2}{3}\right) = -1$$
$$f'(\pi) - \frac{1}{3} = -1 \implies f'(\pi) = -1 + \frac{1}{3} = -\frac{2}{3}$$
정답은 ②번입니다.
