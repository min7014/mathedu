[풀이]
주어진 두 시그마 식을 나열하여 전개합니다.
$$\sum_{k=1}^{10} k a_k = a_1 + 2a_2 + 3a_3 + \cdots + 10a_{10} = 36 \quad \cdots\cdots \text{㉠}$$
$$\sum_{k=1}^9 k a_{k+1} = a_2 + 2a_3 + 3a_4 + \cdots + 9a_{10} = 7 \quad \cdots\cdots \text{㉡}$$
㉠에서 ㉡을 변끼리 빼면 각 항의 계수가 모두 $1$이 됩니다.
$$(a_1 + 2a_2 + \cdots + 10a_{10}) - (a_2 + 2a_3 + \cdots + 9a_{10})$$
$$= a_1 + (2-1)a_2 + (3-2)a_3 + \cdots + (10-9)a_{10}$$
$$= a_1 + a_2 + a_3 + \cdots + a_{10} = \sum_{k=1}^{10} a_k$$
따라서
$$\sum_{k=1}^{10} a_k = 36 - 7 = 29$$
정답은 29 입니다.
Complete Solution: [Solution]
List and expand the two given sigma equations.
$$\sum_{k=1}^{10} k a_k = a_1 + 2a_2 + 3a_3 + \cdots + 10a_{10} = 36 \quad \cdots\cdots \text{㉠}$$
$$\sum_{k=1}^9 k a_{k+1} = a_2 + 2a_3 + 3a_4 + \cdots + 9a_{10} = 7 \quad \cdots\cdots \text{㉡}$$
$$(a_1 + 2a_2 + \cdots + 10a_{10}) - (a_2 + 2a_3 + \cdots + 9a_{10})$$
$$= a_1 + (2-1)a_2 + (3-2)a_3 + \cdots + (10-9)a_{10}$$
