📐 [단계별 상세 풀이 전개]

1단계: 정수 조건으로부터 공비 $r = -\frac{1}{2}$과 공차 $d = -1$ 도출
조건 (나)에서 등비급수가 수렴하므로 $-1 < r < 1$ ($r \neq 0$)입니다.
조건 (가)에서 $a_k = b_3 = 72r^2$, $a_{k+27} = b_4 = 72r^3$은 모두 정수이고:
$$a_{k+27} - a_k = 27d \implies 72r^2(r - 1) = 27d \implies 8r^2(r - 1) = 3d$$ 이를 만족하는 유리수 공비는 $r = -\frac{1}{2}$이며, 이때 $b_3 = 18$, $b_4 = -9$, $d = -1$입니다.

2단계: 자연수 $k = 5$ 결정
$$a_{k+15} = a_k + 15d = 18 - 15 = 3$$ $$\sum_{n=k}^{\infty} b_n = \frac{b_k}{1 - (-1/2)} = \frac{2}{3}b_k = 3 \implies b_k = \frac{9}{2}$$ $b_k = 72\left(-\frac{1}{2}\right)^{k-1} = \frac{9}{2}$에서 $\left(-\frac{1}{2}\right)^{k-1} = \frac{1}{16}$이므로 $k = 5$입니다.

3단계: 구하는 등비급수의 합 계산
$$\sum_{n=1}^{\infty} \frac{b_n}{5^n} = \frac{72/5}{1 - (-1/10)} = \frac{72/5}{11/10} = \frac{144}{11}$$

      • 핵심 개념 및 원리: 조건 (나)에서 무한등비급수 $\sum_{n=k}^\infty b_n$이 수렴하므로 공비 $r$의 범위는 $-1 < r < 1$ ($r \neq 0$)입니다! 또한 $\{a_n\}$의 모든 항은 정수이므로 $b_3 = 72r^2$과 $b_4 = 72r^3$도 모두 정수여야 하고, 그 차 $b_4 - b_3 = 72r^2(r - 1) = 27d$는 $27$의 배수여야 합니다!

📐 [Step-by-Step Rigorous Derivation]

Step 1: Determine parameters
From $72r^2(r-1) = 27d$ with $-1 < r < 1$ and integer terms, we get $r = -\frac{1}{2}$, $b_3 = 18$, $b_4 = -9$, and $d = -1$.
Then $a_{k+15} = 3 = \frac{b_k}{3/2} \implies b_k = \frac{9}{2} \implies k = 5$.

Step 2: Sum the infinite series
$$\sum_{n=1}^{\infty} \frac{b_n}{5^n} = \frac{72/5}{1 - (-1/10)} = \frac{144}{11}$$
