본 문항은 등비급수의 수렴 조건과 합 공식을 등차수열·등비수열의 일반항과 결합하여 미지수를 추론하는 문항입니다.

📐 [단계별 상세 풀이 전개]

1단계: 등비수열 $\{b_n\}$과 등차수열 $\{a_n\}$의 관계 파악
조건으로부터 등비수열 $\{b_n\}$의 첫째항 $b_1 = 72$, 공비 $r = -\frac{1}{2}$을 얻으면 $b_3 = 18$, $b_4 = -9$입니다.
$a_k = b_3 = 18$, $a_{k+27} = b_4 = -9$에서 등차수열 $\{a_n\}$의 공차 $d$는:
$$27d = -9 - 18 = -27 \implies d = -1$$
2단계: 자연수 $k$ 결정
$$a_{k+15} = a_k + 15d = 18 - 15 = 3$$ $$\sum_{n=k}^{\infty} b_n = \frac{b_k}{1 - (-1/2)} = \frac{2}{3}b_k = 3 \implies b_k = \frac{9}{2}$$ $b_k = 72\left(-\frac{1}{2}\right)^{k-1} = \frac{9}{2}$에서 $\left(-\frac{1}{2}\right)^{k-1} = \frac{1}{16}$이므로 $k = 5$입니다.

3단계: 구하는 등비급수의 합 계산
$$\sum_{n=1}^{\infty} \frac{b_n}{5^n} = \frac{72/5}{1 - (-1/10)} = \frac{72/5}{11/10} = \frac{144}{11}$$

✨ [정답 도출 및 실전 점검 포인트]

따라서 $p = 11, q = 144$이므로 $p + q =$ $155$입니다.

📋 [Problem Analysis & Core Concepts]

This problem combines arithmetic and geometric sequences with the sum of an infinite geometric series.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Determine parameters
With $b_1 = 72$ and $r = -\frac{1}{2}$, we have $a_k = b_3 = 18$ and $a_{k+27} = b_4 = -9 \implies d = -1$.
Then $a_{k+15} = 3 = \frac{b_k}{3/2} \implies b_k = \frac{9}{2} \implies k = 5$.

Step 2: Sum the infinite series
$$\sum_{n=1}^{\infty} \frac{b_n}{5^n} = \frac{72/5}{1 - (-1/10)} = \frac{144}{11}$$

✨ [Final Answer & Practical Tips]

Thus $p + q = 11 + 144 =$ $155$.
