제1단계 · 도함수 $f'(x)$의 부정적분 구하기

먼저 알아야 할 지식

$f'(x) = \frac{1}{x} + 4e^{2x}$ 입니다. 각 항을 적분하면 $\int \frac{1}{x}dx = \ln x$, $\int 4e^{2x}dx = 2e^{2x}$ 이므로 $f(x) = \ln x + 2e^{2x} + C$ 입니다.

🎯 최종 문제 + 상세 풀이

[풀이]
점 $(t, f(t))$에서의 접선의 기울기가 $\frac{1+4e^{2t}}{t}$이므로
$$f'(x) = \frac{1+4e^{2x}}{x} = \frac{1}{x} + 4e^{2x} \quad (x > 0)$$
양변을 부정적분하면
$$f(x) = \int \left(\frac{1}{x} + 4e^{2x}\right)dx = \ln x + 2e^{2x} + C$$
$f(1) = 2e^2 + 1$ 이므로
$$f(1) = \ln 1 + 2e^2 + C = 2e^2 + C = 2e^2 + 1 \implies C = 1$$
따라서
$$f(x) = \ln x + 2e^{2x} + 1$$
구하는 $f(e)$의 값은
$$f(e) = \ln e + 2e^{2e} + 1 = 1 + 2e^{2e} + 1 = 2e^{2e} + 2$$
정답은 ④번입니다.
