📐 [단계별 상세 풀이 전개]

1단계: 다항함수 $f(x)$의 차수 결정
$f(x)$를 $n$차 다항식이라 하면 $f'(x)$는 $(n-1)$차 다항식이고 $\{f'(x)\}^2 - 4$는 $2(n-1)$차 다항식입니다.
양변의 차수가 같아야 하므로 $n = 2(n-1) \implies n = 2$, 즉 $f(x)$는 이차함수입니다.

2단계: 도함수 $f'(x)$ 결정
$f'(0) = 1$이므로 일차함수인 도함수를 $f'(x) = ax + 1$ ($a \neq 0$)로 놓을 수 있습니다.
양변을 미분하면 $f'(x) = 2f'(x)f''(x)$이고, $f'(x) \neq 0$이므로:
$$1 = 2f''(x) \implies f''(x) = a = \frac{1}{2}$$ 따라서 $f'(x) = \frac{1}{2}x + 1$입니다.

3단계: $f(4)$의 값 계산
$f'(4) = \frac{1}{2}(4) + 1 = 3$을 주어진 항등식 $f(4) = \{f'(4)\}^2 - 4$에 대입하면:
$$f(4) = 3^2 - 4 = 9 - 4 = 5$$

📐 [Step-by-Step Rigorous Derivation]

Step 1: Degree comparison
Let $\deg(f) = n$. Then $n = 2(n-1) \implies n = 2$.

Step 2: Differentiate both sides
Differentiating $f(x) = \{f'(x)\}^2 - 4$ gives $f'(x) = 2f'(x)f''(x) \implies f''(x) = \frac{1}{2}$.
Since $f'(0) = 1$, we have $f'(x) = \frac{1}{2}x + 1$.

Step 3: Evaluate $f(4)$
Since $f'(4) = 3$, substituting $x = 4$ gives $f(4) = 3^2 - 4 = 5$.

      • Core Principle: Using elementary arithmetic, if a degree-$n$ polynomial's derivative (degree $n-1$) is squared, its degree becomes $2(n-1)$. Equating degrees gives $n = 2(n-1)$.
      • Step Verification ($2$): Solving $n = 2n - 2$ gives $n = 2$, so $f(x)$ is a quadratic function.
  • 🌿 Step 2 · [Coefficient Comparison] Finding the slope $a$ of $f'(x) = ax + b$
      • Core Principle: Since $f'(x) = ax + b$, the leading term of $f(x)$ is $\frac{a}{2}x^2$, while the leading term of $\{f'(x)\}^2$ is $a^2x^2$.
      • Step Verification ($\frac{1}{2}$): Dividing both sides by $a \neq 0$ yields $a = \frac{1}{2}$.
  • 🌱 Step 3 · [Initial Condition] Completing $f'(x)$ using $f'(0) = 1$
      • Core Principle: Substituting $x = 0$ into $f'(x) = \frac{1}{2}x + b$ gives $f'(0) = b = 1$.
      • Step Verification ($3$): $f'(4) = \frac{1}{2}(4) + 1 = 3$.
  • 🌳 Step 4 · [Squaring] Calculating $\{f'(4)\}^2$
      • Core Principle: We can directly substitute $f'(4) = 3$ into the given identity $f(4) = \{f'(4)\}^2 - 4$.
      • Step Verification ($9$): $3^2 = 9$.
  • 💎 Step 5 · [Final Synthesis] Evaluating $f(4) = \{f'(4)\}^2 - 4$
      • Core Principle: Subtract $4$ from $9$ to obtain $f(4)$.
      • Step Verification ($5$): $f(4) = 9 - 4 = 5$ (choice ③).

Therefore, $f(4) = 5$, which is choice ③.
