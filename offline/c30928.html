제2단계 · $\int_0^1 f'(2x)\sin\pi x dx$의 값 구하기Step 2 · Find the value of $\int_0^1 f'(2x)\sin\pi x dx$

먼저 알아야 할 지식

$\int_0^1 g(x)dx = \int_0^1 f'(2x)\sin\pi x dx + \int_0^1 x dx = I + \frac{1}{2}$. 조건식에 의해 $\int_0^1 g^{-1}(x)dx = 2I + \frac{1}{4}$. 합하면 $(I + \frac{1}{2}) + (2I + \frac{1}{4}) = 3I + \frac{3}{4} = 1 \implies 3I = \frac{1}{4} \implies I = \frac{1}{12}$ 입니다.
Prerequisite Knowledge: $\int_0^1 g(x)dx = \int_0^1 f'(2x)\sin\pi x dx + \int_0^1 x dx = I + \frac{1}{2}$. $\int_0^1 g^{-1}(x)dx = 2I + \frac{1}{4}$ by conditional expression. 구하는 식 $\int_0^2 f(x)\cos\frac{\pi x}{2}dx$에서 $x=2t$로 치환하면 $2\int_0^1 f(2t)\cos\pi t dt$ 입니다. $u(t) = f(2t), v'(t) = \cos\pi t$로 부분적분하면 $2\left[\frac{1}{\pi}f(2t)\sin\pi t\right]_0^1 - \frac{4}{\pi}\int_0^1 f'(2t)\sin\pi t dt = 0 - \frac{4}{\pi}\left(\frac{1}{12}\right) = -\frac{1}{3\pi}$ 입니다.
