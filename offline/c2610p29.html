📋 [문제 분석 및 핵심 출제 의도]

본 문항은 정규분포 곡선의 대칭성을 이용하여 떨어진 두 구간의 확률 합을 하나의 연결된 구간 확률로 바꾼 뒤, 두 정규분포의 평균과 표준편차를 추론하는 문항입니다.

📐 [단계별 상세 풀이 전개]

1단계: 평균 $m_1 = 4$ 도출 및 대칭 구간 결합
조건 (가)에서 $\mathrm{P}(X \le 2) = \mathrm{P}(X \ge 6)$이므로 대칭축은 $m_1 = \frac{2+6}{2} = 4$입니다.
평균 $m_1 = 4$에 대한 대칭성에 의해 $\mathrm{P}(1 \le X \le 2) = \mathrm{P}(6 \le X \le 7)$이므로:
$$\mathrm{P}(1 \le X \le 2) + \mathrm{P}(7 \le X \le 9) = \mathrm{P}(6 \le X \le 7) + \mathrm{P}(7 \le X \le 9) = \mathrm{P}(6 \le X \le 9)$$
2단계: $m_2 = 16$과 표준편차 도출
$\mathrm{P}(6 \le X \le 9) = \mathrm{P}(11 \le Y \le 14)$에서 두 구간의 길이가 모두 $3$이고 $f(5) = g(15)$를 만족하므로 $\sigma_1 = \sigma_2$이며, $|5 - 4| = |15 - m_2| = 1$입니다.
구간 $[6, 9]$가 $m_1 = 4$로부터 $+2 \sim +5$만큼 떨어져 있으므로, $m_2 = 16$일 때 구간 $[11, 14]$가 $m_2 = 16$으로부터 $-5 \sim -2$만큼 떨어져 두 조건을 동시에 만족합니다.

3단계: $\mathrm{P}(Y \ge 20)$ 표준화 계산
$\sigma_2 = 10$이므로:
$$k = \mathrm{P}(Y \ge 20) = \mathrm{P}\left(Z \ge \frac{20 - 16}{10}\right) = \mathrm{P}(Z \ge 0.4) = 0.5 - 0.155 = 0.345$$

✨ [정답 도출 및 실전 점검 포인트]

따라서 $1000 \times k = 1000 \times 0.345 =$ $345$입니다.

📋 [Problem Analysis & Core Concepts]

This problem uses normal distribution symmetry to merge disjoint probability intervals and determine the parameters $m_1, m_2, \sigma_2$.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Symmetry of $X$
From $\mathrm{P}(X \le 2) = \mathrm{P}(X \ge 6)$, we get $m_1 = 4$. Reflecting $[1, 2]$ across $4$ gives $[6, 7]$, so $\mathrm{P}(1 \le X \le 2) + \mathrm{P}(7 \le X \le 9) = \mathrm{P}(6 \le X \le 9) = \mathrm{P}(11 \le Y \le 14)$.

Step 2: Parameters of $Y$ and final probability
Combined with $f(5) = g(15)$, we obtain $\sigma_1 = \sigma_2 = 10$ and $m_2 = 16$. Thus:
$$k = \mathrm{P}(Y \ge 20) = \mathrm{P}(Z \ge 0.4) = 0.5 - 0.155 = 0.345$$

✨ [Final Answer & Practical Tips]

Therefore, $1000k =$ $345$.
