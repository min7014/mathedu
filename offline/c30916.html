🔰 제0단계 · 수학 기호

$\log_{\dfrac{1}{3}}(x-4) = -\log_3(x-4)$ — 밑변환 및 지수 추출
$x+2 > 0, x-4 > 0 \implies x > 4$ — 로그의 진수 조건
$(x+2)(x-4) = 3^3 = 27$ — 로그를 지수형태로 변환

제1단계 · 로그의 밑 통일하기

먼저 알아야 할 지식

$\log_{\frac{1}{3}}(x-4) = \log_{3^{-1}}(x-4) = -\log_3(x-4)$ 이므로 주어진 식은 $\log_3(x+2) - \{-\log_3(x-4)\} = \log_3(x+2) + \log_3(x-4) = \log_3\{(x+2)(x-4)\}$ 가 됩니다.

[풀이]
1) 진수 조건:
$$x + 2 > 0 \implies x > -2$$
$$x - 4 > 0 \implies x > 4$$
따라서 $x > 4$ 이어야 합니다.
2) 로그 밑 통일:
$$\log_{\frac{1}{3}}(x-4) = \log_{3^{-1}}(x-4) = -\log_3(x-4)$$
이므로 주어진 방정식은
$$\log_3(x+2) - \{-\log_3(x-4)\} = 3$$
$$\log_3(x+2) + \log_3(x-4) = 3$$
$$\log_3\{(x+2)(x-4)\} = 3$$
$$(x+2)(x-4) = 3^3 = 27$$
$$x^2 - 2x - 8 = 27 \implies x^2 - 2x - 35 = 0$$
$$(x-7)(x+5) = 0$$
진수 조건 $x > 4$에 의하여 $x = 7$ 입니다.
정답은 7 입니다.
