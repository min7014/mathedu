🔰 1단계 · [초등 소거 규칙과 로그 미분] $(\ln(\sec x))' = \tan x$를 이용해 $f'(x)$ 간단히 하기🔰 Step 1 · [Elementary Cancellation & Log Derivative] Simplifying $f'(x)$ using $(\ln(\sec x))' = \tan x$

먼저 알아야 할 지식

함수 $f(x) = x\tan x - \ln(\sec x)$를 미분해 봅시다!
  • 앞부분 $x\tan x$를 곱의 미분법으로 미분하면: $1\cdot\tan x + x\sec^2 x$
  • 뒷부분 $\ln(\sec x)$를 합성함수 미분법으로 미분하면: $\dfrac{(\sec x)'}{\sec x} = \dfrac{\sec x \tan x}{\sec x} = \tan x$
따라서 두 식을 빼면 초등학교 덧셈·뺄셈 소거처럼 $\tan x - \tan x = 0$이 지워집니다!
Prerequisite Knowledge: Differentiating $f(x) = x\tan x - \ln(\sec x)$: the product rule gives $(x\tan x)' = \tan x + x\sec^2 x$, and the chain rule gives $(\ln(\sec x))' = \frac{\sec x\tan x}{\sec x} = \tan x$. Subtracting cancels $\tan x - \tan x = 0$!

$t = \cos^2 s$의 양변을 $s$에 대하여 미분하면:$$\frac{dt}{ds} = 2\cos s(-\sin s) = -\sin(2s)$$여기에 $s = \dfrac{\pi}{4}$를 대입하면 $\dfrac{dt}{ds}$와 그 역수인 $\dfrac{ds}{dt}$를 구할 수 있습니다.

🌳 5단계 · [접선의 $y$절편 $g(t)$ 식 세우기] 접점 $(s, f(s))$와 기울기 $\dfrac{s}{t}$로 $g(t)$ 나타내기🌳 Step 5 · [Formula for $y$-Intercept $g(t)$] Writing $g(t) = f(s) - \dfrac{s^2}{t}$

먼저 알아야 할 지식

점 $(s, f(s))$를 지나고 기울기가 $\dfrac{s}{t}$인 접선 $l$의 방정식은:$$y = \frac{s}{t}(x - s) + f(s) = \frac{s}{t}x + \left\{f(s) - \frac{s^2}{t}\right\}$$따라서 직선 $l$의 $y$절편($x = 0$일 때의 $y$값) $g(t)$는 $f(s) - \dfrac{s^2}{t}$입니다!
Prerequisite Knowledge: The tangent line at $(s, f(s))$ with slope $\frac{s}{t}$ is $y = \frac{s}{t}(x - s) + f(s) = \frac{s}{t}x + f(s) - \frac{s^2}{t}$, so its $y$-intercept is $g(t) = f(s) - \frac{s^2}{t}$.

🌳 6단계 · [$g(t)$ 미분 정리] $g(t) = f(s) - \dfrac{s^2}{t}$를 $t$에 대해 미분하기🌳 Step 6 · [Differentiating $g(t)$] Simplifying $g'(t) = -\dfrac{s}{t}\dfrac{ds}{dt} + \dfrac{s^2}{t^2}$

먼저 알아야 할 지식

$g(t) = f(s) - s^2 \cdot t^{-1}$의 양변을 $t$에 대하여 미분해 봅시다 ($s$도 $t$에 따라 변하는 함수임에 주의!):$$g'(t) = f'(s)\frac{ds}{dt} - \frac{2s}{t}\frac{ds}{dt} + \frac{s^2}{t^2}$$그런데 $f'(s) = \dfrac{s}{t}$이므로, 앞의 두 항을 합치면 $\left(\dfrac{s}{t} - \dfrac{2s}{t}\right)\dfrac{ds}{dt} = -\dfrac{s}{t}\dfrac{ds}{dt}$로 간단해집니다!
Prerequisite Knowledge: Differentiating $g(t) = f(s) - s^2 t^{-1}$ with respect to $t$ and substituting $f'(s) = \frac{s}{t}$ gives $g'(t) = \left(\frac{s}{t} - \frac{2s}{t}\right)\frac{ds}{dt} + \frac{s^2}{t^2} = -\frac{s}{t}\frac{ds}{dt} + \frac{s^2}{t^2}$.

📐 [단계별 상세 풀이 전개]

1단계: 도함수 $f'(x)$와 $t = \cos^2 s$ 도출
$$f'(x) = (\tan x + x\sec^2 x) - \frac{\sec x \tan x}{\sec x} = x\sec^2 x$$ 점 $(s, f(s))$에서의 접선의 기울기가 $\frac{s}{t}$이므로:
$$s\sec^2 s = \frac{s}{t} \implies t = \cos^2 s$$
2단계: $g(t)$의 도함수 구하기
접선 $y = \frac{s}{t}(x - s) + f(s)$의 $y$절편은 $g(t) = f(s) - \frac{s^2}{t}$입니다. 양변을 $t$에 대하여 미분하고 $f'(s) = \frac{s}{t}$를 대입하면:
$$g'(t) = f'(s)\frac{ds}{dt} - \frac{2s}{t}\frac{ds}{dt} + \frac{s^2}{t^2} = -\frac{s}{t}\frac{ds}{dt} + \frac{s^2}{t^2}$$
3단계: $t = \frac{1}{2}$에서의 미분계수 계산
$t = \cos^2 s = \frac{1}{2}$ ($0 < s < \frac{\pi}{2}$)에서 $s = \frac{\pi}{4}$이고, $\frac{dt}{ds} = -\sin(2s) = -1 \implies \frac{ds}{dt} = -1$입니다.
$$g'\!\left(\frac{1}{2}\right) = -\frac{\pi/4}{1/2}(-1) + \frac{\pi^2/16}{1/4} = \frac{\pi}{2} + \frac{\pi^2}{4} = \frac{\pi^2 + 2\pi}{4}$$

🪜 [초등 눈높이 디딤돌 전 단계(1단계~8단계) 완전 연결 상세 해설]

위 디딤돌 문제에서 밟아 온 $1$단계부터 $8$단계까지의 작은 조각들을 순서대로 연결하면 본문항의 풀이가 빈틈없이 완성됩니다.

  • 🔰 1단계 · [초등 소거 규칙과 로그 미분] $(\ln(\sec x))' = \tan x$를 이용해 $f'(x)$ 간단히 하기
      • 핵심 개념 및 원리: 함수 $f(x) = x\tan x - \ln(\sec x)$를 미분해 봅시다!
    • 앞부분 $x\tan x$를 곱의 미분법으로 미분하면: $1\cdot\tan x + x\sec^2 x$
    • 뒷부분 $\ln(\sec x)$를 합성함수 미분법으로 미분하면: $\dfrac{(\sec x)'}{\sec x} = \dfrac{\sec x \tan x}{\sec x} = \tan x$
    따라서 두 식을 빼면 초등학교 덧셈·뺄셈 소거처럼 $\tan x - \tan x = 0$이 지워집니다!
      • 단계 확인 정답 ($x\sec^2 x$): $\tan x$가 소거되어 $f'(x) = x\sec^2 x = \dfrac{x}{\cos^2 x}$만 깔끔하게 남습니다.
  • 🌿 2단계 · [접선의 기울기 조건] $f'(s) = \dfrac{s}{t}$에서 $t$와 $s$의 관계식 찾기
      • 핵심 개념 및 원리: 점 $(s, f(s))$에서의 접선 $l$의 기울기는 $f'(s) = s\sec^2 s = \dfrac{s}{\cos^2 s}$입니다. 문제에서 이 기울기가 $\dfrac{s}{t}$라고 했고 $0 < s < \dfrac{\pi}{2}$이므로 양변의 $s$를 약분하면 $\dfrac{1}{\cos^2 s} = \dfrac{1}{t}$, 즉 $t = \cos^2 s$를 얻습니다!
      • 단계 확인 정답 ($\cos^2 s$): $t = \cos^2 s$입니다.
  • 🌱 3단계 · [특수각 대입] $t = \dfrac{1}{2}$일 때 접점의 $x$좌표 $s$ 구하기
      • 핵심 개념 및 원리: 구하려는 값은 $g'\!\left(\dfrac{1}{2}\right)$, 즉 $t = \dfrac{1}{2}$일 때입니다. $t = \cos^2 s = \dfrac{1}{2}$이고 $0 < s < \dfrac{\pi}{2}$이므로 $\cos s = \dfrac{\sqrt{2}}{2}$입니다.
      • 단계 확인 정답 ($\frac{\pi}{4}$): $\cos\left(\dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{2}$이므로 $s = \dfrac{\pi}{4}$입니다.
  • 🌱 4단계 · [음함수 미분법] $t = \cos^2 s$를 미분하여 $\dfrac{ds}{dt}$ 구하기
      • 핵심 개념 및 원리: $t = \cos^2 s$의 양변을 $s$에 대하여 미분하면:$$\frac{dt}{ds} = 2\cos s(-\sin s) = -\sin(2s)$$여기에 $s = \dfrac{\pi}{4}$를 대입하면 $\dfrac{dt}{ds}$와 그 역수인 $\dfrac{ds}{dt}$를 구할 수 있습니다.
      • 단계 확인 정답 ($-1$): $-\sin\left(\dfrac{\pi}{2}\right) = -1$이므로 역수인 $\dfrac{ds}{dt}$도 $-1$입니다.
  • 🌳 5단계 · [접선의 $y$절편 $g(t)$ 식 세우기] 접점 $(s, f(s))$와 기울기 $\dfrac{s}{t}$로 $g(t)$ 나타내기
      • 핵심 개념 및 원리: 점 $(s, f(s))$를 지나고 기울기가 $\dfrac{s}{t}$인 접선 $l$의 방정식은:$$y = \frac{s}{t}(x - s) + f(s) = \frac{s}{t}x + \left\{f(s) - \frac{s^2}{t}\right\}$$따라서 직선 $l$의 $y$절편($x = 0$일 때의 $y$값) $g(t)$는 $f(s) - \dfrac{s^2}{t}$입니다!
      • 단계 확인 정답 ($f(s) - \frac{s^2}{t}$): $x = 0$을 대입하면 $g(t) = f(s) - \dfrac{s^2}{t}$입니다.
  • 🌳 6단계 · [$g(t)$ 미분 정리] $g(t) = f(s) - \dfrac{s^2}{t}$를 $t$에 대해 미분하기
      • 핵심 개념 및 원리: $g(t) = f(s) - s^2 \cdot t^{-1}$의 양변을 $t$에 대하여 미분해 봅시다 ($s$도 $t$에 따라 변하는 함수임에 주의!):$$g'(t) = f'(s)\frac{ds}{dt} - \frac{2s}{t}\frac{ds}{dt} + \frac{s^2}{t^2}$$그런데 $f'(s) = \dfrac{s}{t}$이므로, 앞의 두 항을 합치면 $\left(\dfrac{s}{t} - \dfrac{2s}{t}\right)\dfrac{ds}{dt} = -\dfrac{s}{t}\dfrac{ds}{dt}$로 간단해집니다!
      • 단계 확인 정답 ($\frac{\pi}{2}$): $-\dfrac{\pi/4}{1/2} \times (-1) = \dfrac{\pi}{2}$입니다.
  • 💎 7단계 · [둘째 항 계산] $t = \dfrac{1}{2}, s = \dfrac{\pi}{4}$일 때 $\dfrac{s^2}{t^2}$ 구하기
      • 핵심 개념 및 원리: 이제 $g'(t)$의 둘째 항 $\dfrac{s^2}{t^2} = \left(\dfrac{s}{t}\right)^2$을 계산합니다. $\dfrac{s}{t} = \dfrac{\pi/4}{1/2} = \dfrac{\pi}{2}$이므로 이를 제곱하면 됩니다!
      • 단계 확인 정답 ($\frac{\pi^2}{4}$): $\left(\dfrac{\pi}{2}\right)^2 = \dfrac{\pi^2}{4}$입니다.
  • 🏆 8단계 · [최종 정답 완성] $g'\!\left(\dfrac{1}{2}\right) = \dfrac{\pi}{2} + \dfrac{\pi^2}{4}$ 통분하여 더하기
      • 핵심 개념 및 원리: 6단계에서 구한 $\dfrac{\pi}{2}$와 7단계에서 구한 $\dfrac{\pi^2}{4}$를 분모 $4$로 통분하여 더하면 최종 정답이 완성됩니다!
      • 단계 확인 정답 ($\frac{\pi^2 + 2\pi}{4}$): $\dfrac{2\pi}{4} + \dfrac{\pi^2}{4} = \dfrac{\pi^2 + 2\pi}{4}$이므로 정답은 ③입니다.

따라서 $g'\!\left(\dfrac{1}{2}\right) = \dfrac{\pi^2 + 2\pi}{4}$이므로 정답은 ③번입니다.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Relate $t$ and $s$
$$f'(s) = s\sec^2 s = \frac{s}{t} \implies t = \cos^2 s$$
Step 2: Differentiate $g(t) = f(s) - \frac{s^2}{t}$
$$g'(t) = \left(f'(s) - \frac{2s}{t}\right)\frac{ds}{dt} + \frac{s^2}{t^2} = -\frac{s}{t}\frac{ds}{dt} + \frac{s^2}{t^2}$$ At $t = \frac{1}{2}$, $s = \frac{\pi}{4}$ and $\frac{dt}{ds} = -\sin\left(\frac{\pi}{2}\right) = -1$, giving $g'\!\left(\frac{1}{2}\right) = \frac{\pi}{2} + \frac{\pi^2}{4} = \frac{\pi^2 + 2\pi}{4}$.

🪜 [Complete Step-by-Step Scaffolding Walkthrough (Steps 1–8)]

Connecting each elementary-grounded scaffolding step from Step 1 to Step 8 completes the entire derivation without any logical gaps:

  • 🔰 Step 1 · [Elementary Cancellation & Log Derivative] Simplifying $f'(x)$ using $(\ln(\sec x))' = \tan x$
      • Core Principle: Differentiating $f(x) = x\tan x - \ln(\sec x)$: the product rule gives $(x\tan x)' = \tan x + x\sec^2 x$, and the chain rule gives $(\ln(\sec x))' = \frac{\sec x\tan x}{\sec x} = \tan x$. Subtracting cancels $\tan x - \tan x = 0$!
      • Step Verification ($x\sec^2 x$): $f'(x) = x\sec^2 x$.
  • 🌿 Step 2 · [Tangent Slope Condition] Relating $t$ and $s$ from $f'(s) = \dfrac{s}{t}$
      • Core Principle: Equating $f'(s) = \frac{s}{\cos^2 s} = \frac{s}{t}$ for $s \in \left(0, \frac{\pi}{2}\right)$ yields $t = \cos^2 s$.
      • Step Verification ($\cos^2 s$): $t = \cos^2 s$.
  • 🌱 Step 3 · [Special Angle] Finding $s$ when $t = \dfrac{1}{2}$
      • Core Principle: When $t = \cos^2 s = \frac{1}{2}$ with $0 < s < \frac{\pi}{2}$, we have $\cos s = \frac{\sqrt{2}}{2}$.
      • Step Verification ($\frac{\pi}{4}$): $s = \dfrac{\pi}{4}$.
  • 🌱 Step 4 · [Implicit Differentiation] Differentiating $t = \cos^2 s$ to find $\dfrac{ds}{dt}$
      • Core Principle: Differentiating $t = \cos^2 s$ gives $\frac{dt}{ds} = -2\cos s\sin s = -\sin(2s)$.
      • Step Verification ($-1$): $\dfrac{dt}{ds} = -1 \implies \dfrac{ds}{dt} = -1$.
  • 🌳 Step 5 · [Formula for $y$-Intercept $g(t)$] Writing $g(t) = f(s) - \dfrac{s^2}{t}$
      • Core Principle: The tangent line at $(s, f(s))$ with slope $\frac{s}{t}$ is $y = \frac{s}{t}(x - s) + f(s) = \frac{s}{t}x + f(s) - \frac{s^2}{t}$, so its $y$-intercept is $g(t) = f(s) - \frac{s^2}{t}$.
      • Step Verification ($f(s) - \frac{s^2}{t}$): $g(t) = f(s) - \dfrac{s^2}{t}$.
  • 🌳 Step 6 · [Differentiating $g(t)$] Simplifying $g'(t) = -\dfrac{s}{t}\dfrac{ds}{dt} + \dfrac{s^2}{t^2}$
      • Core Principle: Differentiating $g(t) = f(s) - s^2 t^{-1}$ with respect to $t$ and substituting $f'(s) = \frac{s}{t}$ gives $g'(t) = \left(\frac{s}{t} - \frac{2s}{t}\right)\frac{ds}{dt} + \frac{s^2}{t^2} = -\frac{s}{t}\frac{ds}{dt} + \frac{s^2}{t^2}$.

      • Step Verification ($\frac{\pi^2}{4}$): $\dfrac{\pi^2}{4}$.
