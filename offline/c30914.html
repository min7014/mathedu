제1단계 · 기울기와 거리 조건으로 $b_n - a_n$ 구하기Step 1 · Find $b_n - a_n$ using slope and distance conditions

먼저 알아야 할 지식

직선의 기울기가 $3$이므로 $\Delta y = 3\Delta x$ 입니다. 피타고라스 정리에 의해 $(\Delta x)^2 + (3\Delta x)^2 = 10(\Delta x)^2 = (n\sqrt{10})^2 = 10n^2 \implies \Delta x = n$. 즉 $b_n - a_n = n$ 입니다.
Prerequisite Knowledge: The slope of the straight line is $3$, so it is $\Delta y = 3\Delta x$. $(\Delta x)^2 + (3\Delta x)^2 = 10(\Delta x)^2 = (n\sqrt{10})^2 = 10n^2 \implies \Delta x = n$ by Pythagorean theorem. That is, $b_n - a_n = n$.

제2단계 · $2^{b_n}$을 $n$에 대한 식으로 표현하기Step 2 Express $2^{b_n}$ as an expression for $n$

먼저 알아야 할 지식

$2^{b_n} - 2^{a_n} = 3n$ 이고 $a_n = b_n - n$ 이므로 $2^{b_n} - 2^{b_n - n} = 2^{b_n}(1 - 2^{-n}) = 3n \implies 2^{b_n} = \frac{3n}{1 - 2^{-n}} = \frac{3n \cdot 2^n}{2^n - 1}$ 입니다.

두 점 $A_n, B_n$의 좌표를 $A_n(a_n, 2^{a_n}), B_n(b_n, 2^{b_n})$ ($a_n < b_n$)이라 합시다.
조건 (가)에 의해 기울기는 $3$이므로
$$\frac{2^{b_n} - 2^{a_n}}{b_n - a_n} = 3 \implies 2^{b_n} - 2^{a_n} = 3(b_n - a_n) \quad \cdots\cdots \text{㉠}$$
조건 (나)에 의해 두 점 사이의 거리가 $n\sqrt{10}$이므로
$$(b_n - a_n)^2 + (2^{b_n} - 2^{a_n})^2 = 10n^2 \quad \cdots\cdots \text{㉡}$$
㉠을 ㉡에 대입하면
$$(b_n - a_n)^2 + 9(b_n - a_n)^2 = 10(b_n - a_n)^2 = 10n^2 \implies b_n - a_n = n$$
따라서 $a_n = b_n - n$이고, 이를 ㉠에 대입하면
$$2^{b_n} - 2^{b_n - n} = 3n \implies 2^{b_n}(1 - 2^{-n}) = 3n$$
$$2^{b_n} = \frac{3n}{1 - 2^{-n}} = \frac{3n \cdot 2^n}{2^n - 1}$$
원의 중심이 직선 $y=x$ 위에 있으므로 원 자체도 직선 $y=x$에 대하여 대칭입니다.
지수함수 $y=2^x$와 로그함수 $y=\log_2 x$는 $y=x$에 대하여 대칭(역함수)이므로,
원이 $y=\log_2 x$와 만나는 두 점은 점 $A_n, B_n$을 직선 $y=x$에 대칭이동한 점 $(2^{a_n}, a_n), (2^{b_n}, b_n)$입니다.
이 두 점의 $x$좌표 중 큰 값은 $x_n = 2^{b_n}$입니다.
따라서
$$x_n = \frac{3n \cdot 2^n}{2^n - 1}$$
각 값을 계산하면
$$x_1 = \frac{3(1)(2)}{1} = 6$$
$$x_2 = \frac{3(2)(4)}{3} = 8$$
$$x_3 = \frac{3(3)(8)}{7} = \frac{72}{7}$$
따라서 구하는 합은
$$x_1 + x_2 + x_3 = 6 + 8 + \frac{72}{7} = 14 + \frac{72}{7} = \frac{98 + 72}{7} = \frac{170}{7}$$
정답은 ⑤번입니다.
