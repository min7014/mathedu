1단계: 신뢰구간의 중점으로 $a$ 구하기
신뢰구간 $[a + 82, a + 84]$의 중점은 표본평균 $\bar{x} = 2a + 80$과 같으므로:
$$\frac{(a + 82) + (a + 84)}{2} = a + 83 = 2a + 80 \implies a = 3$$
2단계: 신뢰구간의 반쪽 길이로 $\sigma$ 구하기

$$1.96 \times \frac{\sigma}{14} = 1 \implies 0.14\sigma = 1 \implies \sigma = \frac{100}{14} = \frac{50}{7}$$

📐 [Step-by-Step Rigorous Derivation]

Step 1: Midpoint equals sample mean
$$a + 83 = 2a + 80 \implies a = 3$$
Step 2: Half-width equals margin of error
$$1.96 \times \frac{\sigma}{\sqrt{196}} = 0.14\sigma = 1 \implies \sigma = \frac{50}{7}$$

      • Core Principle: By elementary averaging, the midpoint between $a + 82$ and $a + 84$ is $a + 83$, which must equal the sample mean $\bar{x} = 2a + 80$.

      • Core Principle: The half-width from the center $a + 83$ to the upper bound $a + 84$ is $1$.
      • Step Verification ($0.14$): $1.96 \div 14 = 0.14$.
  • 🌱 Step 3 · [Fraction Conversion] Solving $0.14\sigma = 1$ for $\sigma$
      • Core Principle: Since $0.14 = \frac{7}{50}$, $\frac{7}{50}\sigma = 1 \implies \sigma = \frac{50}{7}$.
      • Step Verification ($\frac{50}{7}$): $\sigma = \frac{50}{7}$.
  • 🌳 Step 4 · [Numerator Product] Multiplying $a = 3$ and $50$
      • Core Principle: In $a\sigma = 3 \times \frac{50}{7}$, the numerator is $3 \times 50 = 150$.
      • Step Verification ($150$): $3 \times 50 = 150$.
  • 💎 Step 5 · [Final Synthesis] Final value of $a\sigma$
      • Core Principle: $a\sigma = \frac{150}{7}$.
