🔰 제0단계 · 수학 기호

$\dfrac{d}{dx}\int_a^x t f(t)dt = x f(x)$ — 정적분의 x에 대한 미분
$f(x) = x g'(x)$ — 함수 f와 g의 도함수 관계
$[x g(x)]' = x g'(x) + g(x)$ — 곱의 미분법 역연산

🎯 최종 문제 + 상세 풀이

[풀이]
조건 (가)의 양변을 $x$에 대하여 미분하면
$$x f(x) + x g(x) = 12x^3 + 24x^2 - 6x$$
양변을 $x$로 나누면
$$f(x) + g(x) = 12x^2 + 24x - 6 \quad \cdots\cdots \text{㉠}$$
조건 (나)에서 $f(x) = x g'(x)$이므로 이를 ㉠에 대입하면
$$x g'(x) + g(x) = 12x^2 + 24x - 6$$
좌변은 곱의 미분법 $\{x g(x)\}'$과 같으므로
$$\{x g(x)\}' = 12x^2 + 24x - 6$$
양변을 부정적분하면
$$x g(x) = \int (12x^2 + 24x - 6)dx = 4x^3 + 12x^2 - 6x + C$$
$g(x)$는 다항함수이므로 $x=0$일 때 좌변이 $0$이어야 하므로 적분상수 $C = 0$입니다.
따라서
$$g(x) = 4x^2 + 12x - 6$$
구하는 정적분을 계산하면
$$\int_0^3 g(x)dx = \int_0^3 (4x^2 + 12x - 6)dx = \left[\frac{4}{3}x^3 + 6x^2 - 6x\right]_0^3$$
$$= \frac{4}{3}(27) + 6(9) - 6(3) = 36 + 54 - 18 = 72$$
정답은 ①번입니다.
