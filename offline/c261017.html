1단계: 부정적분 $F(x)$ 구하기
$$F(x) = \int (3x^2 + 4x - 1)dx = x^3 + 2x^2 - x + C \quad (\text{단, } C\text{는 적분상수})$$ $F(0) = 1$이므로 $C = 1$이고, $F(x) = x^3 + 2x^2 - x + 1$입니다.

2단계: $F(2)$ 계산하기
$$F(2) = 2^3 + 2(2^2) - 2 + 1 = 8 + 8 - 2 + 1 = 15$$
