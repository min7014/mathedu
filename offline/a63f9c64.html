🎯 최종 문제 + 상세 풀이

문제 분석

a, b, c, d는 자연수(≥1)이고 a+b+c+d=14입니다.

조건 (가): 10a ≥ d → a ≥ ⌈d/10⌉

조건 (나): c < d² → c ≤ d²-1

d의 범위: c≥1이므로 d²>1 → d≥2. a,b,c≥1이므로 d≤11. 따라서 d ∈ {2,3,...,11}.


방법 1: d별로 직접 세기

d를 고정하면 a+b+c = 14-d = S. 각 c에 대해 가능한 a의 개수를 셉니다.

dScmax경우의 수

31189+8+7+6+5+4+3+2=44
41088+7+6+5+4+3+2+1=36
5977+6+5+4+3+2+1=28
6866+5+4+3+2+1=21
7755+4+3+2+1=15
8644+3+2+1=10
9533+2+1=6
10422+1=3
11300

합계: 27+44+36+28+21+15+10+6+3+0 = 190


방법 2: 포함-배제 원리

전체 자연수 해: 13C3 = 286개

위반 1 (10a < d): d=11, a=1, b=c=1 → 1개

위반 2 (c ≥ d²):

d=1: c≥1, a+b=13-c → 11+10+...+1 = 66개

d=2: c≥4, a+b=12-c → 7+6+...+1 = 28개

d=3: c≥9, a+b=11-c → c=9만 가능 → 1개

총 제외: 1+66+28+1 = 96개 (중복 없음)

286 - 96 = 190
