[풀이]
함수 $f(x) = x^3 + ax^2 - 9x + b$의 도함수를 구하면
$$f'(x) = 3x^2 + 2ax - 9$$
함수 $f(x)$가 $x=1$에서 극소이므로 $f'(1) = 0$이어야 합니다.
$$f'(1) = 3(1)^2 + 2a(1) - 9 = 2a - 6 = 0 \implies a = 3$$
$a=3$을 대입하여 $f'(x) = 0$의 두 근을 구하면
$$f'(x) = 3x^2 + 6x - 9 = 3(x+3)(x-1) = 0$$
$$x = -3 \text{ 또는 } x = 1$$
삼차함수의 최고차항 계수가 양수이므로 $x = -3$에서 극댓값을 갖습니다.
극댓값이 28이므로 $f(-3) = 28$입니다.
$$f(-3) = (-3)^3 + 3(-3)^2 - 9(-3) + b = -27 + 27 + 27 + b = 27 + b = 28$$
$$b = 1$$
따라서
$$a + b = 3 + 1 = 4$$
정답은 4 입니다.
