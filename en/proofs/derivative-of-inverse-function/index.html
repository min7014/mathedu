Derivative of inverse function

20-step visual proof · Limits & Calculus · Differential Calculus

Original step-by-step proof (PDF) Construct it in MathLab Split-screen study board Source page & applets

Proof at a glance

Key idea
Reflect the curve y = f(x) and its tangent slope triangle (Δx, Δy) across the line y = x
Proof logic
Reflection across y = x swaps horizontal run Δx and vertical rise Δy, inverting the secant ratio Δx/Δy = 1 / (Δy/Δx); taking the limit yields (f⁻¹)'(y) = 1 / f'(x)
Common misconception
Never confuse the inverse function f⁻¹(y) with the algebraic reciprocal [f(x)]⁻¹ = 1/f(x), and always evaluate f'(x) at the corresponding pre-image x = f⁻¹(y)
What if not?
How does this rule derive (ln x)' = 1/x from (e^y)' = e^y and (arcsin x)' = 1/√(1-x²) from (sin y)' = cos y?
