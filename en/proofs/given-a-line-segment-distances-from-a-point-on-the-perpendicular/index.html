Formal proof verification (Lean 4)

✔ Machine-checked in Lean 4 (0 sorry)

Given Cartesian midpoint 2*mx = ax + bx, 2*my = ay + by_ and dot-product orthogonality to AB, prove squared distance equality distSq(P, A) = distSq(P, B).

View Lean 4 theorem source (perpendicular_bisector_equidistance)
-- 8. [2019111301] Equidistance on a Perpendicular Bisector (Coordinate Proof)
theorem perpendicular_bisector_equidistance
    (ax ay bx by_ mx my px py : Int)
    (hmx : 2 * mx = ax + bx)
    (hmy : 2 * my = ay + by_)
    (hperp : (px - mx) * (bx - ax) + (py - my) * (by_ - ay) = 0) :
    (px - ax) * (px - ax) + (py - ay) * (py - ay) =
      (px - bx) * (px - bx) + (py - by_) * (py - by_) := by
  have h_diff :
      ((px - ax) * (px - ax) + (py - ay) * (py - ay)) -
      ((px - bx) * (px - bx) + (py - by_) * (py - by_)) =
        2 * ((px - mx) * (bx - ax) + (py - my) * (by_ - ay)) := by
    grind
  rw [hperp] at h_diff
  omega
