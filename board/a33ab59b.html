📘 쌍곡선 PF' - PF = 2 조건의 점 P좌표와 삼각형 넓이 (기초→심화)

📋 원본 문제

쌍곡선 $\dfrac{x^2}{1}-\dfrac{y^2}{35}=1$ 위의 점 P에 대하여 $PF'-PF=2$ 라 하자. $\triangle QFF'$ 와 $\triangle PFF'$ 가 닮음이고 $\dfrac{PF+PF'}{FF'}=\dfrac{FF'}{PF'}$ 일 때, 점 P의 x좌표와 $\triangle FPQ$ 의 넓이를 기약분수 $\dfrac{p}{q}\sqrt{581}$ ($p,q$ 서로소)로 나타냈을 때 $p+q$ 의 값을 구하시오.

기초→심화 단계별 5지 선다 퀴즈. 정답 고르면 바로 채점+해설이 열립니다.

🔰 제0단계 · 수학 기호

쌍곡선 — 두 초점에서의 거리 차이가 일정한 점들의 자취. $|PF'-PF|=2a$
초점거리 $2c$ — 두 초점 F, F' 사이 거리. $c^2=a^2+b^2$
거리 $d_1,d_2$ — $d_1=PF,\ d_2=PF'$ (두 초점까지의 거리)
닮음비 — $\triangle QFF'\sim\triangle PFF'$일 때 대응변 비율. 여기선 $\frac{d_1+d_2}{12}=\frac{12}{d_2}$
넓이(행렬식) — 꼭짓점 F를 기준으로 $\tfrac12\left|\det(\overrightarrow{FP},\overrightarrow{FQ})\right|$

🎯 최종 문제 + 상세 풀이

풀이. 주어진 쌍곡선 $\dfrac{x^2}{1}-\dfrac{y^2}{35}=1$ 에서 $a^2=1,\ b^2=35$ 이므로 $c^2=a^2+b^2=36,\ c=6$. 초점은 $F(6,0),\ F'(-6,0)$.

1) 거리차. $PF'-PF=2$ 이므로 $d_2-d_1=2$, 즉 $d_1=d_2-2$.

2) 관계식. $\triangle QFF' \sim \triangle PFF'$ 와 주어진 비율에서 $\dfrac{d_1+d_2}{12}=\dfrac{12}{d_2}$ → $d_2(d_1+d_2)=144$.

3) $d_2$ 구하기. $d_1=d_2-2$ 대입: $d_2(2d_2-2)=144$ → $2d_2^2-2d_2-144=0$ → $d_2^2-d_2-72=0=(d_2-9)(d_2+8)$. 양의해 $d_2=9$, 따라서 $d_1=7$.

4) P의 x좌표. $d_2^2-d_1^2=24x$ 에서 $81-49=32=24x$ → $x=\dfrac{4}{3}$.

5) 넓이. 꼭짓점 F 기준 행렬식으로 $\triangle FPQ$ 넓이 $=\dfrac{882\sqrt{581}}{81}=\dfrac{98\sqrt{581}}{9}$. 기약분수 $\dfrac{p}{q}\sqrt{581}$ 에서 $p=98,\ q=9$ (서로소).

정답: $p+q=107$
