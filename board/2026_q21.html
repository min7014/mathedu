이 문제를 풀기 위해 차례대로 알아야 할 지식 (요약)

L1: **[지식] 미분이란?]** 미분은 '한 순간의 변화율(기울기)'을 구하는 것입니다. 예를 들어 $\displaystyle x^2$ 을 미분하면 $\displaystyle 2x$ 가 됩니다. 문제은 '미분했을 때 $\displaystyle 2x$ 가 되는 원래 식'을 찾으라는 뜻입니다.
L2: **[지식] 거듭제곱 미분법]** $\displaystyle x^n$ 을 미분하면 $\displaystyle n x^{n-1}$ 이 됩니다. $\displaystyle x^3$ 미분은 $\displaystyle 3x^2$, $\displaystyle x$ (=$\displaystyle x^1$) 미분은 $\displaystyle 1$ 입니다.
L3: **[지식] 상수 미분]** 숫자만 있는 항(상수)을 미분하면 0이 됩니다. 예를 들어 $\displaystyle 5$ 를 미분하면 $\displaystyle 0$, $\displaystyle x^2+7$ 을 미분하면 $\displaystyle 2x+0=2x$ 가 됩니다.
L4: **[지식] 역연산 생각하기]** '미분하면 $\displaystyle 2x$ 가 되는 것'을 거꾸로 찾으려면, $\displaystyle 2x$ 에서 거듭제곱을 하나 올리고 앞 숫자를 맞춥니다. $\displaystyle x^2$ 의 미분이 $\displaystyle 2x$ 이므로 후보는 $\displaystyle x^2$ 입니다.
L5: **[지식] 상수가 있어도 됨]** $\displaystyle x^2+5$, $\displaystyle x^2-3$, $\displaystyle x^2+100$ 모두 미분하면 $\displaystyle 2x$ 가 됩니다 (상수 미분=0). 그래서 답은 하나가 아닙니다.
L6: **[지식] 임의상수 C]** '미분하면 $\displaystyle 2x$ 가 되는 식'은 무한히 많습니다. 이들을 모두 나타내기 위해 임의의 상수 $\displaystyle C$ 를 붙여 $\displaystyle x^2+C$ 라 씁니다. $\displaystyle C$ 는 어떤 숫자도 될 수 있습니다.
L7: **[지식] 부정적분 기호]** 미분의 역연산을 '부정적분'이라 하고 기호 $\displaystyle \int$ 로 나타냅니다. $\displaystyle \int 2x\,dx = x^2+C$ 입니다. (마지막 $\displaystyle dx$ 는 x에 대해 적분한다는 표시)
L8: **[지식] 오답 구별]** $\displaystyle 2x+C$ 는 미분하지 않은 채 상수만 더한 것이라 틀립니다. $\displaystyle x^3+C$ 는 미분하면 $\displaystyle 3x^2$ 가 되므로 틀립니다.
L9: **[지식] 최종 확인]** 원래 문제 ' $\displaystyle f'(x)=2x$ 를 만족하는 $\displaystyle f(x)$ ' 의 일반해는 $\displaystyle x^2+C$ 입니다. $\displaystyle C$ 가 들어가야 모든 가능한 해를 포함합니다.
