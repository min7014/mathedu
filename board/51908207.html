📘 카드 교환 주사위 게임 · 4회 후 초기 상태일 때 3번째가 6일 확률 (기초→심화)

📋 원본 문제

문자 'A'가 적힌 카드 3장과 문자 'B'가 적힌 카드 3장을 준비하여 1번째부터 6번째 자리까지 차례로 A, A, A, B, B, B가 되도록 놓는다. 한 개의 주사위를 던져 나온 눈의 수를 $k$라 할 때, $k \le 5$ 이면 $k$번째 자리의 카드와 $(k+1)$번째 자리의 카드를 교환하고, $k = 6$ 이면 카드의 위치를 그대로 둔다. 이 시행을 4회 반복한 결과 카드가 다시 초기 상태인 A, A, A, B, B, B 순서로 놓여 있을 때, 3번째 시행에서 나온 눈의 수가 6일 확률을 구하시오.

기초→심화 단계별 5지 선다 퀴즈. 정답 고르면 바로 채점+해설이 열립니다.

🔰 제0단계 · 수학 기호

카드 교환 — 인접한 두 카드의 위치를 서로 바꾸는 연산. $k$번째와 $(k+1)$번째 카드를 맞바꿈.
주사위 눈 $k$ — 주사위를 던져 나온 눈. $k \in \{1,2,3,4,5,6\}$. $k \le 5$ 이면 교환, $k=6$ 이면 변화 없음(항등변환).
상태 $S$ — 6장 카드의 배치. 초기 상태 $S_0$: A,A,A,B,B,B (자리 1~6). B의 위치로 상태를 표현하기도 함.
조건부 확률 $P(A|B)$ — 사건 $B$가 일어났을 때 사건 $A$가 일어날 확률. $P(A|B) = \frac{P(A \cap B)}{P(B)} = \frac{n(A \cap B)}{n(B)}$ (동등 가능성일 때).
대칭성 — 그래프가 무향(대칭)이면 $N(s \to t,\; m) = N(t \to s,\; m)$. 왕복 경우의 수가 같음.

🎯 최종 문제 + 상세 풀이

풀이.

① 상태 정의. 초기 상태 $S_0$: A,A,A,B,B,B (B의 위치: 4,5,6). $k=1,2,4,5,6$ 이면 $S_0$ 유지(5가지), $k=3$ 이면 $S_1$(A,A,B,A,B,B)로 변화(1가지).

② $S_1$에서의 전이. $S_1$에서 $k=3$ → $S_0$ 복귀(1가지), $k=2$ → $S_2$(A,B,A,A,B,B)(1가지), $k=4$ → $S_3$(A,A,B,B,A,B)(1가지), $k=1,5,6$ → $S_1$ 유지(3가지).

③ 2회 후 상태별 도달 수. $M_2(S_0) = 5 \times 5 + 1 \times 1 = 26$, $M_2(S_1) = 5 \times 1 + 1 \times 3 = 8$, $M_2(S_2) = 1 \times 1 = 1$, $M_2(S_3) = 1 \times 1 = 1$.

④ 4회 후 $S_0$ 총 경우의 수. 대칭성으로 $N_{\text{total}} = 26^2 + 8^2 + 1^2 + 1^2 = 676 + 64 + 1 + 1 = 742$.

⑤ 3번째가 6인 조건부 경우의 수. 3번째 $k=6$이면 $T_6$은 항등변환. 2회 후 상태 = 3회 후 상태 = $S_2$. $S_2 = S_0$ 이면 4번째 $k \in \{1,2,4,5,6\}$(5가지): $26 \times 5 = 130$. $S_2 = S_1$ 이면 4번째 $k=3$(1가지): $8 \times 1 = 8$. 합계 $130 + 8 = 138$.

⑥ 확률. $P = \dfrac{138}{742} = \dfrac{69}{371}$.
