제1단계 · $f(x)$의 부정적분 $F(x)$ 구하기Step 1 · Find the indefinite integral of $f(x)$

먼저 알아야 할 지식

$x \ge 0$일 때 $f(x) = (k-x)e^{-x} \implies F(x) = (x-k+1)e^{-x} + C_1$. $x < 0$일 때 $f(x) = (k+x)e^{-x} \implies F(x) = (-x-k-1)e^{-x} + C_2$. $x=0$에서 연속이므로 $(-k+1)+C_1 = (-k-1)+C_2 \implies C_2 = C_1 + 2$ 입니다.
Prerequisite Knowledge: When $x \ge 0$ is $f(x) = (k-x)e^{-x} \implies F(x) = (x-k+1)e^{-x} + C_1$. When $x < 0$ is $f(x) = (k+x)e^{-x} \implies F(x) = (-x-k-1)e^{-x} + C_2$. It is continuous from $x=0$, so it is $(-k+1)+C_1 = (-k-1)+C_2 \implies C_2 = C_1 + 2$.

제2단계 · 차함수 $h(x) = F(x)-f(x) \ge 0$의 최솟값 분석Step 2 · Minimum value analysis of difference function $h(x) = F(x)-f(x) \ge 0$

먼저 알아야 할 지식

$h'(x) = 0$의 해는 $x = \frac{2k+1}{2} (>0)$ 및 $x = \frac{1-2k}{2}$ 입니다. $k \le 1/2$이면 최솟값은 $x=0$에서 발생하고 $C_1 \ge 0 \implies F(0) \ge -k+1$. $k > 1/2$이면 최솟값은 $x = \frac{1-2k}{2}$에서 발생하여 $F(0) \ge -k + 2e^{\frac{2k-1}{2}} - 1$ 입니다.
Prerequisite Knowledge: The solutions of $h'(x) = 0$ are $x = \frac{2k+1}{2} (>0)$ and $x = \frac{1-2k}{2}$. If $k \le 1/2$, then the minimum occurs at $x=0$ and $C_1 \ge 0 \implies F(0) \ge -k+1$. If $k > 1/2$, then the minimum occurs from $x = \frac{1-2k}{2}$, which is $F(0) \ge -k + 2e^{\frac{2k-1}{2}} - 1$.

제3단계 · $g(1/4) + g(3/2)$ 및 $100(p+q)$ 계산하기Step 3 Calculate $g(1/4) + g(3/2)$ and $100(p+q)$

$k = 1/4 \le 1/2 \implies g(1/4) = -1/4 + 1 = 3/4$. $k = 3/2 > 1/2 \implies g(3/2) = -3/2 + 2e^{\frac{3-1}{2}} - 1 = 2e - 5/2$. 합: $3/4 + 2e - 5/2 = 2e - 7/4 = pe + q$. 따라서 $p=2, q=-7/4 \implies p+q = 2 - 7/4 = 1/4$. $100(p+q) = 100 \times \frac{1}{4} = 25$ 입니다.
Prerequisite Knowledge: $k = 1/4 \le 1/2 \implies g(1/4) = -1/4 + 1 = 3/4$. $k = 3/2 > 1/2 \implies g(3/2) = -3/2 + 2e^{\frac{3-1}{2}} - 1 = 2e - 5/2$. Sum: $3/4 + 2e - 5/2 = 2e - 7/4 = pe + q$. Therefore, $p=2, q=-7/4 \implies p+q = 2 - 7/4 = 1/4$. This is $100(p+q) = 100 \times \frac{1}{4} = 25$.

$x$의 부호에 따라 $f(x)$를 나누어 한 부정적분 $F(x)$를 구합니다.
$$f(x) = \begin{cases} (k-x)e^{-x} & (x \ge 0) \\ (k+x)e^{-x} & (x < 0) \end{cases}$$
부분적분을 적용하여 $F(x)$를 구하면
$$F(x) = \begin{cases} (x-k+1)e^{-x} + C_1 & (x \ge 0) \\ (-x-k-1)e^{-x} + C_2 & (x < 0) \end{cases}$$
$F(x)$가 실수 전체에서 미분가능하므로 $x=0$에서 연속이어야 합니다.
$$\lim_{x \to 0^+} F(x) = -k + 1 + C_1, \quad \lim_{x \to 0^-} F(x) = -k - 1 + C_2$$
$$-k + 1 + C_1 = -k - 1 + C_2 \implies C_2 = C_1 + 2$$
$F(0) = -k + 1 + C_1$ 이므로, $F(0)$의 최솟값 $g(k)$는 $C_1$의 최솟값에 의해 결정됩니다.
조건 $F(x) \ge f(x)$를 만족시키기 위해 차함수 $h(x) = F(x) - f(x)$를 둡니다.
$$h(x) = \begin{cases} (2x-2k+1)e^{-x} + C_1 & (x \ge 0) \\ (-2x-2k-1)e^{-x} + C_1 + 2 & (x < 0) \end{cases}$$
$h'(x) = 0$이 되는 점을 조사하면
$x > 0$일 때 $x = \frac{2k+1}{2}$, $x < 0$일 때 $x = \frac{1-2k}{2}$ 입니다.
1) $0 < k \le \frac{1}{2}$ 일 때:
$\frac{1-2k}{2} \ge 0$이므로 $x < 0$에서 $h'(x) < 0$입니다. 최솟값은 $x \to \infty$ 또는 $x=0$ 부근에서 결정되며, 모든 실수 $x$에서 $h(x) \ge 0$이려면 $C_1 \ge 0$이어야 합니다.
$$g(k) = -k + 1$$
$$g\left(\frac{1}{4}\right) = -\frac{1}{4} + 1 = \frac{3}{4}$$
2) $k > \frac{1}{2}$ 일 때:
$x = \frac{1-2k}{2} < 0$에서 극소이자 최솟값을 갖습니다.
$$h\left(\frac{1-2k}{2}\right) = -2e^{\frac{2k-1}{2}} + C_1 + 2 \ge 0 \implies C_1 \ge 2e^{\frac{2k-1}{2}} - 2$$
따라서 $F(0) = -k + 1 + C_1 \ge -k + 2e^{\frac{2k-1}{2}} - 1$ 이므로
$$g(k) = -k + 2e^{\frac{2k-1}{2}} - 1$$
$$g\left(\frac{3}{2}\right) = -\frac{3}{2} + 2e^{\frac{3-1}{2}} - 1 = 2e - \frac{5}{2}$$
두 값의 합을 구하면
$$g\left(\frac{1}{4}\right) + g\left(\frac{3}{2}\right) = \frac{3}{4} + \left(2e - \frac{5}{2}\right) = 2e - \frac{7}{4}$$
따라서 $p = 2, q = -\frac{7}{4}$ 입니다.
$$p + q = 2 - \frac{7}{4} = \frac{1}{4}$$
$$100(p + q) = 100 \times \frac{1}{4} = 25$$
정답은 25 입니다.
