🔰 제0단계 · 수학 기호 번역기🔰 Step 0 · Mathematical Symbol Translator

$u = g(x) = (x - b)^2 \implies du = g'(x)dx$ — 두 번째 적분 $\int_b^{b+1} f(g(x))g'(x)dx$를 $\int_0^1 f(u)du$로 바꾸는 치환적분
Substitution $u = g(x)$ transforming the second integral into $\int_0^1 f(u)du$.
$H(x) = g(f(x)) = \{1 - \sin(ax)\}^2$ — 미분하면 $H'(x) = g'(f(x))f'(x)$가 되는 합성함수
Composite function whose derivative is $g'(f(x))f'(x)$.
$\int_0^{2\pi} |H'(x)|dx = \dfrac{5}{4}$ — 구간 $[0, 2\pi]$에서 합성함수 $H(x)$가 위아래로 움직인 총 변화량
Total vertical variation of $H(x) = g(f(x))$ over $[0, 2\pi]$.

🔰 1단계 · [두 번째 적분 치환하기] $u = g(x) = (x - b)^2$일 때 적분 구간 $[b, b+1]$ 바꾸기🔰 Step 1 · [Substituting $u = g(x)$] Changing limits $[b, b+1]$ for $u = (x - b)^2$

먼저 알아야 할 지식

두 번째 조건식 $\int_b^{b+1} f(g(x))g'(x)dx = \dfrac{\cos a}{a}$에서 $u = g(x) = (x - b)^2$으로 치환해 봅시다!
  • $x = b$일 때: $u = g(b) = (b - b)^2 = 0$
  • $x = b + 1$일 때: $u = g(b + 1) = (b + 1 - b)^2 = 1^2 = 1$
  • $g'(x)dx = du$이므로 적분식은 아주 간단한 $\int_0^1 f(u)du$가 됩니다!
Prerequisite Knowledge: In $\int_b^{b+1} f(g(x))g'(x)dx$, let $u = g(x) = (x - b)^2$. At $x = b$, $u = 0$; at $x = b + 1$, $u = 1$. Since $g'(x)dx = du$, the integral becomes $\int_0^1 f(u)du$.

🌿 2단계 · [정적분 계산으로 관계식 도출] $\int_0^1 \{-\sin(au) + b + 1\}du = \dfrac{\cos a}{a}$에서 $b + 1$ 구하기🌿 Step 2 · [Evaluating $\int_0^1 f(u)du$] Deriving $b + 1 = \dfrac{1}{a}$

먼저 알아야 할 지식

$f(u) = -\sin(au) + b + 1$을 $0$부터 $1$까지 적분하면:$$\left[\frac{\cos(au)}{a} + (b + 1)u\right]_0^1 = \left(\frac{\cos a}{a} + b + 1\right) - \frac{1}{a} = \frac{\cos a}{a} + b + 1 - \frac{1}{a}$$이 값이 우변 $\dfrac{\cos a}{a}$와 같으므로 양변에서 $\dfrac{\cos a}{a}$를 지우면 $b + 1 = \dfrac{1}{a}$을 얻습니다!
Prerequisite Knowledge: Integrating $f(u) = -\sin(au) + b + 1$ on $[0, 1]$ gives $\frac{\cos a - 1}{a} + b + 1 = \frac{\cos a}{a}$, which simplifies to $b + 1 = \frac{1}{a}$.

🌱 3단계 · [첫 번째 적분의 합성함수 해석] $H(x) = g(f(x)) = \{1 - \sin(ax)\}^2$ 만들기🌱 Step 3 · [Composite Function $H(x)$] Writing $H(x) = g(f(x)) = \{1 - \sin(ax)\}^2$

먼저 알아야 할 지식

첫 번째 적분식 $\int_0^{2\pi} |g'(f(x))f'(x)|dx = \dfrac{5}{4}$을 자세히 보세요!
  • 합성함수의 미분법에 의해 $g'(f(x))f'(x)$는 바로 합성함수 $H(x) = g(f(x))$를 미분한 도함수 $H'(x)$입니다!
  • $g(x) = (x - b)^2$에 $f(x) = -\sin(ax) + b + 1$을 대입하면 $b$가 지워져서:$$H(x) = \{f(x) - b\}^2 = \{1 - \sin(ax)\}^2$$이 됩니다!
Prerequisite Knowledge: By the Chain Rule, $g'(f(x))f'(x)$ is the derivative of $H(x) = g(f(x)) = \{f(x) - b\}^2 = \{1 - \sin(ax)\}^2$.

🌱 4단계 · [총 이동 거리(절댓값 적분) 계산] $1 + \{1 - \sin(2\pi a)\}^2 = \dfrac{5}{4}$ 풀기🌱 Step 4 · [Total Variation Distance] Solving $1 + \{1 - \sin(2\pi a)\}^2 = \dfrac{5}{4}$

먼저 알아야 할 지식

$\int_0^{2\pi} |H'(x)|dx = \dfrac{5}{4}$는 $x = 0$부터 $x = 2\pi$까지 $H(x)$가 움직인 총 이동 거리가 $\dfrac{5}{4}$라는 뜻입니다!
  • $H(x)$는 $H(0) = 1$에서 출발하여 $ax = \dfrac{\pi}{2}$일 때 최솟값 $0$까지 내려갑니다 ($\implies$ 내려간 거리 $= 1 - 0 = 1$).
  • 총 이동 거리가 $\dfrac{5}{4} = 1 + \dfrac{1}{4}$이 되려면, 최솟값 $0$을 찍은 뒤 $x = 2\pi$에서의 값 $H(2\pi) = \{1 - \sin(2\pi a)\}^2$이 정확히 $\dfrac{1}{4}$만큼만 다시 올라가야 합니다!
Prerequisite Knowledge: Since $H(x)$ starts at $H(0) = 1$ and drops to $0$ at $ax = \frac{\pi}{2}$ (distance $1$), a total travel distance of $\frac{5}{4}$ means it must rise from $0$ to $H(2\pi) = \{1 - \sin(2\pi a)\}^2 = \frac{5}{4} - 1 = \frac{1}{4}$.

제4단계🌱 4단계 · [총 이동 거리(절댓값 적분) 계산] $1 + \{1 - \sin(2\pi a)\}^2 = \dfrac{5}{4}$ 풀기 ⇒ $\frac{1}{2}$다음 단계 연결 ➔
제5단계🌳 5단계 · [각 $2\pi a$와 상수 $a$ 결정] $\dfrac{\pi}{2} < 2\pi a < \dfrac{3\pi}{2}$에서 $a = \dfrac{5}{12}$ 구하기 ⇒ $\frac{5}{12}$다음 단계 연결 ➔
제6단계🌳 6단계 · [$b + 1$ 값 확정] $a = \dfrac{5}{12}$일 때 $b + 1 = \dfrac{1}{a}$ 구하기 ⇒ $\frac{12}{5}$다음 단계 연결 ➔
제7단계💎 7단계 · [$f(2\pi)$ 함숫값 계산] $f(2\pi) = -\sin(2\pi a) + (b + 1)$ 통분하기 ⇒ $\frac{19}{10}$다음 단계 연결 ➔
제8단계🏆 8단계 · [최종 정답 완성] 서로소인 자연수 $p + q$ 구하기 ⇒ $29$정답: $29$

📐 [단계별 상세 풀이 전개]

1단계: 두 번째 정적분 조건 해석 ($u = g(x)$ 치환)
두 번째 적분에서 $u = g(x) = (x - b)^2$으로 치환하면 $g'(x)dx = du$이고 적분 구간은 $[0, 1]$이 됩니다:
$$\int_0^1 \{-\sin(au) + b + 1\}du = \left[\frac{\cos(au)}{a} + (b+1)u\right]_0^1 = \frac{\cos a - 1}{a} + b + 1 = \frac{\cos a}{a} \implies b + 1 = \frac{1}{a}$$
2단계: 첫 번째 절댓값 정적분 조건 해석
$H(x) = g(f(x)) = \{1 - \sin(ax)\}^2$이라 하면 $H'(x) = g'(f(x))f'(x)$입니다.
따라서 첫 번째 조건 $\int_0^{2\pi} |H'(x)|dx = \frac{5}{4}$는 구간 $[0, 2\pi]$에서 $H(x)$의 총변화량이 $\frac{5}{4}$임을 뜻합니다.
$H(0) = 1$에서 출발하여 $ax = \frac{\pi}{2}$에서 최솟값 $0$을 찍고 다시 $H(2\pi) = \{1 - \sin(2\pi a)\}^2$으로 증가하므로 ($\frac{\pi}{2} < 2\pi a < \frac{3\pi}{2}$):
$$(1 - 0) + \{1 - \sin(2\pi a)\}^2 = \frac{5}{4} \implies \{1 - \sin(2\pi a)\}^2 = \frac{1}{4} \implies \sin(2\pi a) = \frac{1}{2}$$ $\frac{\pi}{2} < 2\pi a < \frac{3\pi}{2}$이므로 $2\pi a = \frac{5\pi}{6} \implies a = \frac{5}{12}$입니다.

3단계: $f(2\pi)$의 값 도출
$$f(2\pi) = -\sin\left(\frac{5\pi}{6}\right) + \frac{1}{a} = -\frac{1}{2} + \frac{12}{5} = \frac{19}{10}$$

🪜 [초등 눈높이 디딤돌 전 단계(1단계~8단계) 완전 연결 상세 해설]

위 디딤돌 문제에서 밟아 온 $1$단계부터 $8$단계까지의 작은 조각들을 순서대로 연결하면 본문항의 풀이가 빈틈없이 완성됩니다.

  • 🔰 1단계 · [두 번째 적분 치환하기] $u = g(x) = (x - b)^2$일 때 적분 구간 $[b, b+1]$ 바꾸기
      • 핵심 개념 및 원리: 두 번째 조건식 $\int_b^{b+1} f(g(x))g'(x)dx = \dfrac{\cos a}{a}$에서 $u = g(x) = (x - b)^2$으로 치환해 봅시다!
    • $x = b$일 때: $u = g(b) = (b - b)^2 = 0$
    • $x = b + 1$일 때: $u = g(b + 1) = (b + 1 - b)^2 = 1^2 = 1$
    • $g'(x)dx = du$이므로 적분식은 아주 간단한 $\int_0^1 f(u)du$가 됩니다!

      • 단계 확인 정답 ($[0, 1]$): $g(b) = 0^2 = 0$, $g(b+1) = 1^2 = 1$이므로 적분 구간은 $[0, 1]$이 됩니다.
  • 🌿 2단계 · [정적분 계산으로 관계식 도출] $\int_0^1 \{-\sin(au) + b + 1\}du = \dfrac{\cos a}{a}$에서 $b + 1$ 구하기
      • 핵심 개념 및 원리: $f(u) = -\sin(au) + b + 1$을 $0$부터 $1$까지 적분하면:$$\left[\frac{\cos(au)}{a} + (b + 1)u\right]_0^1 = \left(\frac{\cos a}{a} + b + 1\right) - \frac{1}{a} = \frac{\cos a}{a} + b + 1 - \frac{1}{a}$$이 값이 우변 $\dfrac{\cos a}{a}$와 같으므로 양변에서 $\dfrac{\cos a}{a}$를 지우면 $b + 1 = \dfrac{1}{a}$을 얻습니다!
      • 단계 확인 정답 ($\frac{1}{a}$): $b + 1 - \dfrac{1}{a} = 0 \implies b + 1 = \dfrac{1}{a}$입니다.
  • 🌱 3단계 · [첫 번째 적분의 합성함수 해석] $H(x) = g(f(x)) = \{1 - \sin(ax)\}^2$ 만들기
      • 핵심 개념 및 원리: 첫 번째 적분식 $\int_0^{2\pi} |g'(f(x))f'(x)|dx = \dfrac{5}{4}$을 자세히 보세요!
    • 합성함수의 미분법에 의해 $g'(f(x))f'(x)$는 바로 합성함수 $H(x) = g(f(x))$를 미분한 도함수 $H'(x)$입니다!
    • $g(x) = (x - b)^2$에 $f(x) = -\sin(ax) + b + 1$을 대입하면 $b$가 지워져서:$$H(x) = \{f(x) - b\}^2 = \{1 - \sin(ax)\}^2$$이 됩니다!

      • 단계 확인 정답 ($H(0) = 1$, 최솟값 $= 0$): $x = 0$일 때 $\sin 0 = 0$이므로 $H(0) = 1^2 = 1$이고, $\sin(ax) = 1$일 때 $H(x) = (1 - 1)^2 = 0$(최솟값)입니다.
  • 🌱 4단계 · [총 이동 거리(절댓값 적분) 계산] $1 + \{1 - \sin(2\pi a)\}^2 = \dfrac{5}{4}$ 풀기
      • 핵심 개념 및 원리: $\int_0^{2\pi} |H'(x)|dx = \dfrac{5}{4}$는 $x = 0$부터 $x = 2\pi$까지 $H(x)$가 움직인 총 이동 거리가 $\dfrac{5}{4}$라는 뜻입니다!
    • $H(x)$는 $H(0) = 1$에서 출발하여 $ax = \dfrac{\pi}{2}$일 때 최솟값 $0$까지 내려갑니다 ($\implies$ 내려간 거리 $= 1 - 0 = 1$).
    • 총 이동 거리가 $\dfrac{5}{4} = 1 + \dfrac{1}{4}$이 되려면, 최솟값 $0$을 찍은 뒤 $x = 2\pi$에서의 값 $H(2\pi) = \{1 - \sin(2\pi a)\}^2$이 정확히 $\dfrac{1}{4}$만큼만 다시 올라가야 합니다!

      • 단계 확인 정답 ($\frac{1}{2}$): $1 - \sin(2\pi a) = \dfrac{1}{2} \implies \sin(2\pi a) = \dfrac{1}{2}$입니다.
  • 🌳 5단계 · [각 $2\pi a$와 상수 $a$ 결정] $\dfrac{\pi}{2} < 2\pi a < \dfrac{3\pi}{2}$에서 $a = \dfrac{5}{12}$ 구하기
      • 핵심 개념 및 원리: $H(x)$가 $ax = \dfrac{\pi}{2}$에서 최솟값 $0$을 찍고 난 뒤 단조증가하는 구간($\dfrac{\pi}{2} < ax < \dfrac{3\pi}{2}$) 안에 끝점 $2\pi a$가 있어야 합니다!
    • $\dfrac{\pi}{2} < 2\pi a < \dfrac{3\pi}{2}$에서 $\sin(2\pi a) = \dfrac{1}{2}$을 만족시키는 각은 제2사분면의 각 $2\pi a = \dfrac{5\pi}{6}$입니다!

      • 단계 확인 정답 ($\frac{5}{12}$): $a = \dfrac{5\pi}{6 \times 2\pi} = \dfrac{5}{12}$입니다.
  • 🌳 6단계 · [$b + 1$ 값 확정] $a = \dfrac{5}{12}$일 때 $b + 1 = \dfrac{1}{a}$ 구하기
      • 핵심 개념 및 원리: 2단계에서 $b + 1 = \dfrac{1}{a}$을 구했으므로, 5단계의 $a = \dfrac{5}{12}$의 역수를 취하면 $b + 1$의 값이 바로 나옵니다!
      • 단계 확인 정답 ($\frac{12}{5}$): $b + 1 = \dfrac{12}{5}$입니다.
  • 💎 7단계 · [$f(2\pi)$ 함숫값 계산] $f(2\pi) = -\sin(2\pi a) + (b + 1)$ 통분하기
      • 핵심 개념 및 원리: $f(x) = -\sin(ax) + b + 1$에 $x = 2\pi$를 대입하면:$$f(2\pi) = -\sin(2\pi a) + (b + 1) = -\frac{1}{2} + \frac{12}{5}$$
      • 단계 확인 정답 ($\frac{19}{10}$): $\dfrac{-5 + 24}{10} = \dfrac{19}{10}$입니다.
  • 🏆 8단계 · [최종 정답 완성] 서로소인 자연수 $p + q$ 구하기
      • 핵심 개념 및 원리: $\dfrac{q}{p} = \dfrac{19}{10}$에서 $p = 10, q = 19$이므로 $p + q = 29$입니다.
      • 단계 확인 정답 ($29$): $10 + 19 = 29$입니다.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Second integral via $u = g(x)$
$$\int_0^1 f(u)du = \frac{\cos a - 1}{a} + b + 1 = \frac{\cos a}{a} \implies b + 1 = \frac{1}{a}$$
Step 2: First integral via total variation of $H(x) = \{1 - \sin(ax)\}^2$
$$(1 - 0) + \{1 - \sin(2\pi a)\}^2 = \frac{5}{4} \implies \sin(2\pi a) = \frac{1}{2} \implies 2\pi a = \frac{5\pi}{6} \implies a = \frac{5}{12}$$ Thus $f(2\pi) = -\frac{1}{2} + \frac{12}{5} = \frac{19}{10}$ and $p + q = 29$.

Connecting each elementary-grounded scaffolding step from Step 1 to Step 8 completes the entire derivation without any logical gaps:

  • 🔰 Step 1 · [Substituting $u = g(x)$] Changing limits $[b, b+1]$ for $u = (x - b)^2$
      • Core Principle: In $\int_b^{b+1} f(g(x))g'(x)dx$, let $u = g(x) = (x - b)^2$. At $x = b$, $u = 0$; at $x = b + 1$, $u = 1$. Since $g'(x)dx = du$, the integral becomes $\int_0^1 f(u)du$.
      • Step Verification ($[0, 1]$): $[0, 1]$.
  • 🌿 Step 2 · [Evaluating $\int_0^1 f(u)du$] Deriving $b + 1 = \dfrac{1}{a}$
      • Core Principle: Integrating $f(u) = -\sin(au) + b + 1$ on $[0, 1]$ gives $\frac{\cos a - 1}{a} + b + 1 = \frac{\cos a}{a}$, which simplifies to $b + 1 = \frac{1}{a}$.
      • Step Verification ($\frac{1}{a}$): $b + 1 = \dfrac{1}{a}$.
  • 🌱 Step 3 · [Composite Function $H(x)$] Writing $H(x) = g(f(x)) = \{1 - \sin(ax)\}^2$
      • Core Principle: By the Chain Rule, $g'(f(x))f'(x)$ is the derivative of $H(x) = g(f(x)) = \{f(x) - b\}^2 = \{1 - \sin(ax)\}^2$.
      • Step Verification ($H(0) = 1$, 최솟값 $= 0$): $H(0) = 1$ and minimum $= 0$.
  • 🌱 Step 4 · [Total Variation Distance] Solving $1 + \{1 - \sin(2\pi a)\}^2 = \dfrac{5}{4}$
      • Core Principle: Since $H(x)$ starts at $H(0) = 1$ and drops to $0$ at $ax = \frac{\pi}{2}$ (distance $1$), a total travel distance of $\frac{5}{4}$ means it must rise from $0$ to $H(2\pi) = \{1 - \sin(2\pi a)\}^2 = \frac{5}{4} - 1 = \frac{1}{4}$.
      • Step Verification ($\frac{1}{2}$): $\sin(2\pi a) = \dfrac{1}{2}$.
  • 🌳 Step 5 · [Determining $a$] Finding $2\pi a = \dfrac{5\pi}{6}$ and $a = \dfrac{5}{12}$
      • Core Principle: Since $2\pi a$ must lie after the minimum at $\frac{\pi}{2}$ and before $\frac{3\pi}{2}$, $\sin(2\pi a) = \frac{1}{2}$ gives $2\pi a = \frac{5\pi}{6}$.
      • Step Verification ($\frac{5}{12}$): $a = \dfrac{5}{12}$.
  • 🌳 Step 6 · [Evaluating $b + 1$] Computing $b + 1 = \dfrac{1}{a}$ for $a = \dfrac{5}{12}$
      • Core Principle: Taking the reciprocal of $a = \frac{5}{12}$ gives $b + 1 = \frac{1}{a} = \frac{12}{5}$.
      • Step Verification ($\frac{12}{5}$): $b + 1 = \dfrac{12}{5}$.

      • Core Principle: Substitute $\sin(2\pi a) = \frac{1}{2}$ and $b + 1 = \frac{12}{5}$ into $f(2\pi) = -\sin(2\pi a) + b + 1$.
