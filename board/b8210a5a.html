🔰 제0단계 · 이차함수의 기본 개념 익히기

먼저 알아야 할 지식

이차함수 f(x) = ax^2 + bx + c (a \neq 0)의 그래프는 포물선이다. a > 0이면 위로 열리고, a < 0이면 아래로 열린다. 꼭짓점의 x좌표는 x = -b/(2a)이고, 이때의 최솟값(또는 최댓값)은 f(-b/(2a))로 구한다. 예를 들어 f(x) = x^2 - 4x + 3에서 a=1, b=-4, c=3이므로 꼭짓점의 x좌표는 x = -(-4)/(2\cdot1) = 2이고, f(2) = 4 - 8 + 3 = -1이므로 최솟값은 -1이다.

🔰 제1단계 · 꼭짓점과 최솟값 조건 분석하기

🎯 최종 문제 + 상세 풀이

풀이 과정:

  1. 최솟값 조건 설정: f(x) = x^2 - 2ax + a + 2의 꼭짓점은 x = a에서이며, f(a) = -a^2 + a + 2. 최솟값이 1이므로 -a^2 + a + 2 = 1 \Rightarrow a^2 - a - 1 = 0.
  2. a의 값 구하기: 근의 공식으로 a = (1 \pm \sqrt{5})/2.
  3. 교점 조건 분석: f(x) = 2x + 1에서 x^2 - (2a+2)x + (a+1) = 0. 판별식 D/4 = (a+1)^2 - (a+1) = a(a+1).
  4. 각 a에 대한 판별:
    • a = (1+\sqrt{5})/2 \approx 1.618: a > 0, a+1 > 0 \Rightarrow D > 0 \Rightarrow 교점 2개
    • a = (1-\sqrt{5})/2 \approx -0.618: a < 0, a+1 > 0 \Rightarrow D < 0 \Rightarrow 교점 0개
  5. 결론: a = (1+\sqrt{5})/2일 때 교점은 2개. a = (1-\sqrt{5})/2일 때 교점은 0개. 두 근 모두 고려하나, 최종 답은 교점 2개.
