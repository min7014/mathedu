🔰 제0단계 · 수학 기호

$T = \dfrac{2\pi}{a}$ — 함수 $y = 2\sin(ax)$의 기본 주기 ($a > 0$)
$\sin(ax) = \dfrac{1}{2}$ — 직선 $y = 1$과의 교점을 구하기 위한 기본 삼각방정식
$\text{밑변 } AB = \dfrac{2\pi}{3a}$ — 대칭성을 이용한 교점 $A, B$ 사이의 가로 거리
$\text{높이 } h = 3$ — 직선 $y=1$과 최솟값 $y=-2$ 사이의 수직 거리 ($1 - (-2) = 3$)

🔰 제1단계 · 삼각함수 $f(x)$의 주기와 치역 구하기

먼저 알아야 할 지식

함수 $y = A\sin(Bx)$ ($A > 0, B > 0$)의 주기는 $T = \frac{2\pi}{B}$이고, 치역은 $-A \le y \le A$입니다. 따라서 최댓값은 $A$, 최솟값은 $-A$입니다.

🎯 최종 문제 + 상세 풀이

[전체 풀이 과정 종합]
1단계: 곡선 $y = 2\sin(ax)$와 직선 $y = 1$의 교점의 $x$좌표를 구하기 위해 방정식을 세운다.
$$2\sin(ax) = 1 \implies \sin(ax) = \frac{1}{2}$$
$0 \le x \le \frac{2\pi}{a}$에서 $0 \le ax \le 2\pi$이므로,
$$ax = \frac{\pi}{6} \text{ 또는 } ax = \frac{5\pi}{6}$$
따라서 두 교점의 $x$좌표는 $x_A = \frac{\pi}{6a}, x_B = \frac{5\pi}{6a}$이다.
2단계: 선분 $AB$는 직선 $y=1$ 위에 있으므로 밑변의 길이는
$$AB = x_B - x_A = \frac{5\pi}{6a} - \frac{\pi}{6a} = \frac{4\pi}{6a} = \frac{2\pi}{3a}$$
3단계: 함수 $f(x) = 2\sin(ax)$의 최솟값은 $-2$이므로 점 $C$의 $y$좌표는 $-2$이다.
직선 $y=1$과 점 $C$ 사이의 수직 높이 $h$는
$$h = 1 - (-2) = 3$$
4단계: 삼각형 $ABC$의 넓이 $S$는
$$S = \frac{1}{2} \times AB \times h = \frac{1}{2} \times \frac{2\pi}{3a} \times 3 = \frac{\pi}{a}$$
문제에서 넓이가 $6$이라 하였으므로
$$\frac{\pi}{a} = 6 \implies a = \frac{\pi}{6}$$
최종 본문항
양수 $a$에 대하여 함수 $f(x) = 2\sin(ax) \quad \left(0 \le x \le \frac{2\pi}{a}\right)$의 그래프가 직선 $y = 1$과 만나는 서로 다른 두 점을 각각 $A, B$라 하고, 함수 $f(x)$가 최솟값을 갖는 점을 $C$라 하자. 삼각형 $ABC$의 넓이가 $6$일 때, 양수 $a$의 값은? (단, $x_A < x_B$)
1$\frac{\pi}{6}$
2$\frac{\pi}{5}$
3$\frac{\pi}{4}$
