🎯 최종 문제 + 상세 풀이

풀이 과정:

① 교점 구하기: $x^2-4x+3 = -x+3$에서 $x^2-3x=0$, 즉 $x(x-3)=0$이므로 교점의 $x$좌표는 $x=0$과 $x=3$. 대응되는 $y$좌표는 각각 $y=3$과 $y=0$이므로 교점은 $(0,3)$과 $(3,0)$.

② 위·아래 판단: $x=1$을 대입하면 포물선: $y=1-4+3=0$, 직선: $y=-1+3=2$. 따라서 구간 $[0,3]$에서 직선이 포물선 위에 있음.

③ 적분 설정: $S = \int_0^3 [(-x+3)-(x^2-4x+3)]\,dx = \int_0^3 (-x^2+3x)\,dx$.

④ 적분 계산: $S = \left[-\frac{x^3}{3}+\frac{3x^2}{2}\right]_0^3 = \left(-\frac{27}{3}+\frac{27}{2}\right) - 0 = -9+\frac{27}{2} = \frac{-18+27}{2} = \frac{9}{2}$.

⑤ 결론: 둘러싸인 도형의 넓이는 $\boxed{\dfrac{9}{2}}$입니다.
