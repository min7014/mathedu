$6$의 약수는 $1$, $2$, $3$, $6$이므로 조건 (가)에서
$f(1) \times f(6)=1$ 또는 $f(1) \times f(6)=2$
$f(1) \times f(6)=3$ 또는 $f(1) \times f(6)=6$
(i) $f(1) \times f(6)=1$일 때
$f(1)=f(6)=1$
따라서 조건 (나)에서
$2 \leq f(2) \leq f(3) \leq f(4) \leq f(5) \leq 2$
즉, $f(2)=f(3)=f(4)=f(5)=2$
따라서 이 조건을 만족시키는
함수 $f$의 개수는 $1$이다.
(ii) $f(1) \times f(6)=2$일 때
$f(1) \leq f(6)$ 이므로 $f(1)=1$, $f(6)=2$
따라서 조건 (나)에서
$2 \leq f(2) \leq f(3) \leq f(4) \leq f(5) \leq 4$
이므로 $f(2)$, $f(3)$, $f(4)$, $f(5)$의 값을
정하는 경우의 수는 $2$, $3$, $4$ 중에서
중복을 허락하여 $4$개를 선택하는 중복조합의 수와 같으므로
$\, _ { 3 } H _ { 4 } =\, _ { 3+4-1 } C _ { 4 }$
$=\, _ { 6 } C _ { 4 }$
$=\, _ { 6 } C _ { 2 }$
$= \cfrac{ 6 \times 5 } { 2 \times 1 } =15$
따라서 이 조건을 만족시키는
함수 $f$의 개수는 $15$이다.
