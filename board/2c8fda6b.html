📋 원본 문제

최고차항의 계수가 1이고 f(0)=3, f'(3)<0인 사차함수 f(x)가 있다. 실수 t에 대하여 집합 S를 S = { a | 함수 |f(x)-t|가 x=a에서 미분가능하지 않다 } 라 하고, 집합 S의 원소의 개수를 g(t)라 하자. 함수 g(t)가 t=3과 t=19에서만 불연속일 때, f(-2)의 값을 구하시오.

기초→심화 단계별 5지 선다 퀴즈. 정답 고르면 바로 채점+해설이 열립니다.

🔰 제0단계 · 수학 기호

사차함수 — 최고차항이 4차인 다항식 함수. 그래프는 일반적으로 W자 또는 U자 모양
미분가능성 — 어떤 점에서 좌우 미분계수가 같고, 그 점에서 접선의 기울기가 유일하게 정해지는 성질
절댓값 함수 |h(x)| — h(x)가 음수인 구간을 뒤집어 양수로 만든 함수. h(x)=0인 점에서 미분 불가능할 수 있음
임계점 — f'(x)=0이 되는 점. 극값(극대·극소)이 생기는 후보 지점
원소 개수 함수 g(t) — 집합 S의 원소 개수를 t에 따라 세는 함수. t가 변할 때 불연속점이 생길 수 있음

🎯 최종 문제 + 상세 풀이

풀이

1. |f(x)-t|는 f(x)=t이고 f'(x)≠0인 점에서 미분 불가능 → S는 그러한 점들의 집합.

2. g(t)가 t=3,19에서만 불연속 → f는 두 개의 임계값(극값) 3,19를 가짐. 사차함수가 3개 임계점에 임계값 2개 → 두 극소점 y값 동일.

3. f(0)=3 → x=0은 극소점. f'(3)<0 → x=3에서 감소 중. W자형 대칭구조에서 두 극소점은 x=0, x=4, 극대점은 x=2.

4. f(x)=(x(x-4))^2+3=x^4-8x^3+16x^2+3. 조건 검증: f(0)=3, f'(3)=-12<0, f(4)=3(극소), f(2)=19(극대).

5. f(-2)=(-2)^4-8(-2)^3+16(-2)^2+3=16+64+64+3=147.
