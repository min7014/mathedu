📐 [단계별 상세 풀이 전개]

1단계: 부등식 $1 \le \mathrm{V}(X) \le \sigma(X)$에서 $\mathrm{V}(X)$ 확정하기
표준편차 $s = \sigma(X) \ge 0$이라 놓으면 $\mathrm{V}(X) = s^2$이므로 주어진 부등식은 $1 \le s^2 \le s$입니다.
• $1 \le s^2$이고 $s \ge 0$이므로 $s \ge 1$입니다.
• 동시에 $s^2 \le s \iff s(s - 1) \le 0$이므로 $0 \le s \le 1$입니다.
따라서 $s = 1$, 즉 $\mathrm{V}(X) = 1$이 유일하게 성립합니다.

2단계: 확률의 총합과 대칭성을 이용한 분산 $\mathrm{V}(X)$ 정리
모든 확률의 합은 $1$이므로 $$2a^2 + 2a + 2b = 1 \implies a^2 + a + b = \frac{1}{2} \implies 8b = 4 - 8a - 8a^2$$ 또한 모든 확률은 $0$ 이상이어야 하므로 $a \ge 0$이고 $b = \dfrac{1}{2} - a - a^2 \ge 0$이어야 합니다.
확률분포표가 $X = 0$에 대하여 대칭이므로 기댓값은 $$\mathrm{E}(X) = (-3k)a^2 + (-2k)b + (-k)a + ka + 2kb + 3ka^2 = 0$$ 따라서 분산 $\mathrm{V}(X) = \mathrm{E}(X^2) - \{\mathrm{E}(X)\}^2 = \mathrm{E}(X^2)$를 계산하면: $$\mathrm{V}(X) = 2\left\{(3k)^2 a^2 + (2k)^2 b + k^2 a\right\} = k^2(18a^2 + 8b + 2a)$$ 여기에 $8b = 4 - 8a - 8a^2$을 대입하면: $$\mathrm{V}(X) = k^2\left(18a^2 + 4 - 8a - 8a^2 + 2a\right) = k^2(10a^2 - 6a + 4) = 1$$ 3단계: 완전제곱식으로 $k^2$의 최댓값과 유효성 검증하기
$$k^2 = \frac{1}{10a^2 - 6a + 4} = \frac{1}{10\left(a - \dfrac{3}{10}\right)^2 + \dfrac{31}{10}}$$ $a = \dfrac{3}{10}$일 때 $a > 0$, $a^2 = \dfrac{9}{100} > 0$, 그리고 $b = \dfrac{1}{2} - \dfrac{3}{10} - \dfrac{9}{100} = \dfrac{11}{100} > 0$이므로 유효한 확률분포 조건을 완벽히 만족합니다!
따라서 분모의 최솟값은 $\dfrac{31}{10}$이고, $k^2$의 최댓값은 역수인 $\dfrac{10}{31}$입니다.

🪜 [초등 눈높이 디딤돌 전 단계(1단계~5단계) 완전 연결 상세 해설]

위 디딤돌 문제에서 밟아 온 $1$단계부터 $5$단계까지의 작은 조각들을 순서대로 연결하면 본문항의 풀이가 빈틈없이 완성됩니다.

      • 핵심 개념 및 원리: 초등학교 곱셈 감각을 떠올려 봅시다! $1$보다 큰 수(예: $2$)는 두 번 곱하면 $2 \times 2 = 4$로 원래 수보다 커져서 $s^2 \le s$가 깨지고, $1$보다 작은 양수(예: $0.5$)는 두 번 곱하면 $0.25$로 $1$보다 작아져서 $1 \le s^2$이 깨집니다. 따라서 $1 \le s^2 \le s$를 동시에 만족하는 양수 $s = \sigma(X)$는 오직 $1$뿐입니다!
      • 단계 확인 정답 ($1$): $s = \sigma(X) \ge 0$이라 하면 $1 \le s^2$에서 $s \ge 1$이고 $s^2 \le s$에서 $0 \le s \le 1$이므로 $s = 1$, 즉 $\mathrm{V}(X) = 1$입니다.
  • 🌿 2단계 · [확률 총합과 대칭 평균] $\mathrm{E}(X)=0$과 $2b = 1 - 2a - 2a^2$ 도출하기
      • 핵심 개념 및 원리: 확률변수 값 $-3k, -2k, -k, k, 2k, 3k$와 확률 $a^2, b, a, a, b, a^2$가 $0$을 기준으로 좌우 완벽 대칭이므로 평균은 계산할 필요도 없이 $\mathrm{E}(X) = 0$이고, 확률의 총합에서 $2a^2 + 2a + 2b = 1$입니다.
      • 단계 확인 정답 ($\mathrm{E}(X)=0,\quad 8b = 4 - 8a - 8a^2$): 원점 대칭이므로 $\mathrm{E}(X)=0$이고, $2b = 1 - 2a - 2a^2$의 양변에 $4$를 곱하면 $8b = 4 - 8a - 8a^2$입니다.
  • 🌱 3단계 · [분산 식 정리] $\mathrm{V}(X) = k^2(10a^2 - 6a + 4)$ 유도하기
      • 핵심 개념 및 원리: $\mathrm{E}(X)=0$이므로 $\mathrm{V}(X) = \mathrm{E}(X^2) = 2\{(3k)^2 a^2 + (2k)^2 b + k^2 a\} = k^2(18a^2 + 8b + 2a)$입니다. 여기에 $8b = 4 - 8a - 8a^2$을 대입합니다.

  • 🌳 4단계 · [이차함수 최솟값] $10a^2 - 6a + 4$의 최솟값과 확률 양수 조건 확인
      • 핵심 개념 및 원리: $k^2 = \dfrac{1}{10a^2 - 6a + 4}$이 최대가 되려면 분모 $f(a) = 10a^2 - 6a + 4 = 10\left(a - \dfrac{3}{10}\right)^2 + \dfrac{31}{10}$이 최소가 되어야 합니다. 꼭짓점 $a = \dfrac{3}{10}$일 때 $b = \dfrac{1}{2} - \dfrac{3}{10} - \dfrac{9}{100} = \dfrac{11}{100} > 0$이므로 모든 확률이 $0$ 이상인 조건도 완벽히 통과합니다!
      • 단계 확인 정답 ($\dfrac{31}{10}$): $4 - 10 \times \dfrac{9}{100} = 4 - \dfrac{9}{10} = \dfrac{31}{10}$이며, $a=\dfrac{3}{10}$일 때 $b=\dfrac{11}{100}>0$이므로 최솟값은 $\dfrac{31}{10}$입니다.
  • 💎 5단계 · [최종 종합] $k^2$의 최댓값 $\dfrac{q}{p}$와 $p+q$ 구하기
      • 핵심 개념 및 원리: $k^2 = \dfrac{1}{10a^2 - 6a + 4}$의 최댓값은 분모가 최소인 $\dfrac{31}{10}$일 때 $\dfrac{1}{\frac{31}{10}} = \dfrac{10}{31}$입니다. $31$과 $10$은 서로소이므로 $p = 31, q = 10 \implies p + q = 41$입니다.
      • 단계 확인 정답 ($41$): $p = 31,\; q = 10$이므로 $p + q = 31 + 10 = 41$입니다.

📋 [Problem Analysis & Core Concepts]

This short-answer problem combines three key ideas: squeezing $1 \le \mathrm{V}(X) \le \sigma(X)$ to $\mathrm{V}(X) = 1$, exploiting origin symmetry ($\mathrm{E}(X) = 0$), and minimizing a quadratic in $a$ subject to non-negative probabilities.

📐 [Step-by-Step Rigorous Derivation]

Step 1: Deduce $\mathrm{V}(X) = 1$
Let $s = \sigma(X) \ge 0$. Then $1 \le s^2 \le s$ implies both $s \ge 1$ and $0 \le s \le 1$, so $s = 1$ and $\mathrm{V}(X) = 1$.

Step 2: Express $\mathrm{V}(X)$ in terms of $k$ and $a$
Probabilities sum to $1$: $2a^2 + 2a + 2b = 1 \implies 8b = 4 - 8a - 8a^2$. By symmetry, $\mathrm{E}(X) = 0$, so $$1 = \mathrm{V}(X) = \mathrm{E}(X^2) = k^2(18a^2 + 8b + 2a) = k^2(10a^2 - 6a + 4)$$ Step 3: Maximize $k^2$ via completing the square
$$10a^2 - 6a + 4 = 10\left(a - \frac{3}{10}\right)^2 + \frac{31}{10}$$ At $a = \dfrac{3}{10}$, all probabilities are valid ($b = \dfrac{1}{2} - \dfrac{3}{10} - \dfrac{9}{100} = \dfrac{11}{100} > 0$), so the minimum of the denominator is $\dfrac{31}{10}$ and $\max(k^2) = \dfrac{10}{31}$.

🪜 [Complete Step-by-Step Scaffolding Walkthrough (Steps 1–5)]

Connecting each elementary-grounded scaffolding step from Step 1 to Step 5 completes the entire derivation without any logical gaps:

  • 🔰 Step 1 · [Elementary Intuition] Finding the unique number satisfying $1 \le s^2 \le s$
      • Core Principle: By elementary number sense: if $s > 1$, then $s^2 > s$; if $0 \le s < 1$, then $s^2 < 1$. Hence the only $s \ge 0$ satisfying $1 \le s^2 \le s$ is $s = 1$, so $\mathrm{V}(X) = 1$!
      • Step Verification ($1$): $1 \le s^2 \le s$ with $s \ge 0$ forces $s = 1$, so $\mathrm{V}(X) = 1$.
  • 🌿 Step 2 · [Total Probability & Symmetry] Deriving $\mathrm{E}(X)=0$ and $2b = 1 - 2a - 2a^2$
      • Core Principle: By symmetry around $0$, $\mathrm{E}(X) = 0$, and summing all probabilities gives $2a^2 + 2a + 2b = 1 \implies 2b = 1 - 2a - 2a^2$.
      • Step Verification ($\mathrm{E}(X)=0,\quad 8b = 4 - 8a - 8a^2$): $\mathrm{E}(X)=0$, and multiplying $2b = 1 - 2a - 2a^2$ by $4$ gives $8b = 4 - 8a - 8a^2$.
  • 🌱 Step 3 · [Variance Formula] Simplifying $\mathrm{V}(X)$ into $k^2(10a^2 - 6a + 4)$
      • Core Principle: Substitute $8b = 4 - 8a - 8a^2$ into $\mathrm{V}(X) = k^2(18a^2 + 8b + 2a)$ to eliminate $b$.
      • Step Verification ($k^2(10a^2 - 6a + 4)$): $18a^2 + (4 - 8a - 8a^2) + 2a = 10a^2 - 6a + 4$.
  • 🌳 Step 4 · [Quadratic Minimum] Minimum of $10a^2 - 6a + 4$ and valid probability check
      • Core Principle: Completing the square gives $10\left(a - \frac{3}{10}\right)^2 + \frac{31}{10}$. At $a = \frac{3}{10}$, $b = \frac{11}{100} > 0$ is a valid probability, so the minimum of the denominator is $\frac{31}{10}$.
      • Step Verification ($\dfrac{31}{10}$): $4 - \dfrac{9}{10} = \dfrac{31}{10}$, achieved at $a = \dfrac{3}{10}$ where $b = \dfrac{11}{100} > 0$.
  • 💎 Step 5 · [Final Synthesis] Finding $\max(k^2) = \dfrac{q}{p}$ and $p + q$
      • Core Principle: Taking the reciprocal of $\dfrac{31}{10}$ gives $\max(k^2) = \dfrac{10}{31}$, so $p = 31, q = 10$, and $p + q = 41$.
      • Step Verification ($41$): $p + q = 31 + 10 = 41$.

✨ [Conclusion & Key Takeaways]

Since $p = 31$ and $q = 10$ are coprime natural numbers, $p + q = 31 + 10 = \mathbf{41}$.
