먼저 알아야 할 지식

부정적분 공식 $\int x^n\,dx = \frac{1}{n+1}x^{n+1} + C$에 의해, $\int (6x^2 - 2x)\,dx = 6 \left(\frac{1}{3}x^3\right) - 2\left(\frac{1}{2}x^2\right) + C = 2x^3 - x^2 + C$ 입니다.
Prerequisite Knowledge: By the indefinite integral formula $\int x^n\,dx = \frac{1}{n+1}x^{n+1} + C$, it is $\int (6x^2 - 2x)\,dx = 6 \left(\frac{1}{3}x^3\right) - 2\left(\frac{1}{2}x^2\right) + C = 2x^3 - x^2 + C$.

🌿 2단계 · [적분상수의 결정] 초기조건 $f(0)$의 대입🌿 Step 2 · [Determination of integration constant] Substitution of initial condition $f(0)$

먼저 알아야 할 지식

$f(x) = 2x^3 - x^2 + C$에 $x=0$을 대입하면 $f(0) = 0 - 0 + C = C$ 입니다. 문제에서 $f(0) = 10$이라 주어졌으므로 적분상수 $C = 10$으로 확정됩니다.
Prerequisite Knowledge: If you substitute $x=0$ into $f(x) = 2x^3 - x^2 + C$, you get $f(0) = 0 - 0 + C = C$. Since $f(0) = 10$ is given in the problem, the integration constant is confirmed as $C = 10$.
