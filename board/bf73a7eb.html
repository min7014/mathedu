📘 포물선과 직선의 교점과 면적

기초→심화 단계별 5지선다 퀴즈. 정답 고르면 바로 채점+해설이 열립니다.

🔰 제0단계 · 수학 기호

y = ax² + bx + c — 이차함수(포물선)의 일반형. a≠0이며, a>0이면 위로 볼록, a<0이면 아래로 볼록
y = mx + n — 직선의 방정식. m은 기울기, n은 y절편
Δ = b² - 4ac — 이차방정식 ax²+bx+c=0의 판별식. Δ>0이면 두 개의 실근, Δ=0이면 중근, Δ<0이면 실근 없음
x = [-b ± √Δ] / 2a — 이차방정식의 근의 공식. 두 근 x₁, x₂를 구하는 식
|AB| = √{(x₂-x₁)² + (y₂-y₁)²} — 두 점 A(x₁,y₁), B(x₂,y₂) 사이의 거리 공식

🔰 제0단계 · 핵심 기호와 정의 익히기

먼저 알아야 할 지식

수학 문제에서 등장하는 기호의 의미를 먼저 파악해야 합니다. 이 문제에서 사용되는 핵심 기호를 정리하면: - $y = ax^2 + bx + c$ : 이차함수(포물선)의 일반형입니다. $a \neq 0$이며, $a > 0$이면 위로 볼록, $a < 0$이면 아래로 볼록합니다. - $y = mx + n$ : 직선의 방정식입니다. $m$은 기울기, $n$은 $y$절편입니다. - $\Delta = b^2 - 4ac$ : 판별식으로, 이차방정식의 근의 개수를 결정합니다. - $x = \frac{-b \pm \sqrt{\Delta}}{2a}$ : 근의 공식으로, 두 근 $x_1, x_2$를 구합니다.

🔰 제1단계 · 이차함수의 꼭짓점 구하기

먼저 알아야 할 지식

이차함수 $y = ax^2 + bx + c$의 꼭짓점은 완전제곱식으로 변형하여 구합니다: $y = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a}$ 꼭짓점의 $x$좌표는 $x = -\frac{b}{2a}$, $y$좌표는 $y = \frac{4ac-b^2}{4a}$입니다. 이 형태를 **꼭짓점 형태** $y = a(x-h)^2 + k$라 하면, 꼭짓점은 $(h, k)$입니다.

2$y = (x-3)^2 - 4$
3$y = (x+3)^2 - 4$
4$y = (x-6)^2 + 5$
5$y = (x-3)^2 + 14$
문항
이차함수 $y = 2x^2 + 4x - 1$의 꼭짓점 좌표는?
1$(1, 5)$

🔰 제2단계 · 이차함수와 x축의 교점

먼저 알아야 할 지식

이차함수 $y = ax^2 + bx + c$와 $x$축의 교점은 $y = 0$으로 놓고 풀면 됩니다: $ax^2 + bx + c = 0$ 근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 사용하면 두 교점의 $x$좌표를 구할 수 있습니다. 두 근을 $x_1, x_2$라 하면: - $x_1 + x_2 = -\frac{b}{a}$ (비에타 공식) - $x_1 \cdot x_2 = \frac{c}{a}$ (비에타 공식)

🔰 제3단계 · 직선의 방정식과 그래프 읽기

먼저 알아야 할 지식

직선 $y = mx + n$에서: - $m$은 기울기(직선의 기울기 정도) - $n$은 $y$절편 ($x=0$일 때의 $y$값) 두 점 $(x_1, y_1)$, $(x_2, y_2)$를 지나는 직선의 기울기는: $m = \frac{y_2 - y_1}{x_2 - x_1}$ 두 직선이 수직이려면 기울기의 곱이 $-1$이어야 합니다: $m_1 \cdot m_2 = -1$ 두 직선이 평행하려면 기울기가 같아야 합니다: $m_1 = m_2$
문항

1$m = 1$
2$m = 2$
3$m = 3$
4$m = 4$
5$m = 6$
문항
직선 $y = 2x + 1$과 직선 $y = -\frac{1}{2}x + 3$의 위치관계는?
1평행하다

🔰 제4단계 · 연립방정식으로 교점 찾기

먼저 알아야 할 지식

포물선 $y = ax^2 + bx + c$와 직선 $y = mx + n$의 교점을 구하려면 두 식을 연립합니다: $ax^2 + bx + c = mx + n$ $ax^2 + (b-m)x + (c-n) = 0$ 이 이차방정식의 해가 교점의 $x$좌표입니다. 판별식에 따라: - $\Delta > 0$: 두 교점 - $\Delta = 0$: 한 접점(직선이 포물선에 접함) - $\Delta < 0$: 교점 없음(직선과 포물선이 만나지 않음)

2$x^2 - 2x + 3 = 0$
3$x^2 + 4x - 3 = 0$
4$x^2 + 2x - 1 = 0$
5$x^2 - 3x + 4 = 0$
문항

🔰 제5단계 · 교점 좌표 구하기 (구체적 계산)

먼저 알아야 할 지식

연립방정식으로 구한 $x$값을 원래 식(직선 또는 포물선)에 대입하면 $y$좌표를 구할 수 있습니다. 두 점 사이의 거리: $|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ 삼각형의 면적(세 점 $O(0,0)$, $A(x_1,y_1)$, $B(x_2,y_2)$): $S = \frac{1}{2}|x_1 y_2 - x_2 y_1|$

🔰 제6단계 · 포물선과 직선이 둘러싸는 면적

먼저 알아야 할 지식

포물선 $y = f(x)$와 직선 $y = g(x)$가 둘러싸는 면적은: $S = \left|\int_{x_1}^{x_2} [f(x) - g(x)]\, dx\right|$ 여기서 $x_1, x_2$는 교점의 $x$좌표입니다. 핵심 단계: 1. 교점의 $x$좌표 $x_1, x_2$ 구하기 2. $f(x) - g(x)$ 정리하기 (위쪽 함수 - 아래쪽 함수) 3. 정적분 계산하기 $f(x) - g(x) = ax^2 + (b-m)x + (c-n)$ 형태로 정리되면, 이를 인수분해하면 $a(x-x_1)(x-x_2)$가 되어 계산이 간단해집니다.

🔰 제7단계 · 접선 조건으로 매개변수 구하기

먼저 알아야 할 지식

포물선 $y = x^2 + bx + c$와 직선 $y = mx + n$이 접할 때, 매개변수의 관계를 구합니다.\n\n접선 조건: 연립방정식의 판별식 $\Delta = 0$\n\n$x^2 + bx + c = mx + n$\n$x^2 + (b-m)x + (c-n) = 0$\n\n$\Delta = (b-m)^2 - 4(c-n) = 0$\n\n이 식을 통해 한 변수를 다른 변수로 표현할 수 있습니다. 접점의 $x$좌표는 $x = -\frac{b-m}{2}$로 구할 수 있습니다.

2$b = 2$ 또는 $b = -6$
3$b = 4$ 또는 $b = -4$
4$b = -4$ 또는 $b = 4$
5$$b = 0$$ 또는 $b = 4$

🎯 최종 문제 + 상세 풀이

포물선 y = x² - 6x + 8과 직선 y = 2x - 4로 둘러싸인 영역의 넓이

\n\n

1단계: 교점 구하기

\n

두 곡선을 연립합니다:

\n

$x^2 - 6x + 8 = 2x - 4$

\n

$x^2 - 8x + 12 = 0$

\n

$(x-2)(x-6) = 0$

\n

$\therefore x = 2, \; x = 6$

\n\n

2단계: 위쪽/아래쪽 함수 판단

\n

$x = 4$ (중간값)에서 확인:

\n

포물선: $4^2 - 6(4) + 8 = 0$

\n

직선: $2(4) - 4 = 4$

\n

$\therefore 0 < x < 6$ 구간에서 직선이 포물선 위에 있습니다.

\n\n

3단계: 정적분 계산

\n

$S = \int_2^6 [(-x^2+8x-12)]\,dx$

\n

$= \left[-\frac{x^3}{3} + 4x^2 - 12x\right]_2^6$

\n

$= \left(-\frac{216}{3} + 144 - 72\right) - \left(-\frac{8}{3} + 16 - 24\right)$

\n

$= 0 - \left(-\frac{32}{3}\right) = \frac{32}{3}$

\n\n

최종 답: $\frac{32}{3}$
